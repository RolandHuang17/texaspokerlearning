# 谁决定尺度：频率法与范围法的分工

<!-- hands: 2 -->
<!-- terms: frequency-approach,range-approach,betting-frequency,checking-frequency,bet-size,minimum-defense-frequency,fold-frequency,indifference,value-bet,bluff,combos,nut-advantage,capped-range -->

## 本节目标 / Objectives

- 能写出并亲手验证这条闭合式：`EV(bet) − EV(check) = f·p·(1−e) + (1−f)·b·(2e−1)`，并说出哪一项属于频率法、哪一项属于范围法。
- 给定任意（尺度、对手弃牌率）组合，能说出 `break_even_equity_to_bet` 返回的区间（`above` / `below` / `all` / `none`）各自对应"哪一段范围该下注"。
- 能用生成表的行号指出三处**只由频率决定**的结论，和两处**必须靠范围构成**才能得出的结论，并说清它们为什么不是同一件事。

## 前置知识 / Prerequisites

- `02-03` 最低防守频率（MDF）：`MDF = p/(p+b)`，以及它只是"诈唬所需弃牌率"的补，不是一手牌的门槛。
- `02-04` 无差别（indifference）：价值与诈唬的比例由尺度决定，由 `table.02-04.bluff-value-ratio` 现算。
- `03-02` 封顶范围（capped-range）：`is_capped` 只回答"这条行动线里有没有坚果"，它管的是威胁的可信度，不是尺度数字本身。

## 核心原理 / The principle

同一街上的两个动作（下注 / 过牌）之间，尺度由两个互相独立的问题决定：**频率决定这条尺度能不能被使用，牌力决定范围里的哪一段有资格使用它。**
把两者写进同一条等式就是：下注相对过牌的期望值之差等于 `f·p·(1−e) + (1−f)·b·(2e−1)`，第一项只含尺度与弃牌率，第二项只含尺度与牌力。这是 `derived` 结论：它由 `pokergto.ev` 的四行定义推出，不依赖任何 solver、任何人的表。

## 推导 / Derivation

符号先定义完再用：`p` 是行动者加注**之前**底池里的钱，`b` 是行动者必须加进去的钱，`f` 是**所有**对手都弃牌的频率（声明输入，见"来源与置信度"），`e` 是钱进池后行动者的胜率。参考点是弃牌，所以已经埋进底池的钱不出现在任何一项里。

### 第一步：两个动作各值多少

```
EV(bet)   = f·p + (1−f)·( e·(p + 2b) − b )
EV(check) = e·p
```

### 第二步：作差，把它拆成两半

```
EV(bet) − EV(check) = f·p − f·e·p + (1−f)·b·(2e − 1)
                    = f·p·(1−e)  +  (1−f)·b·(2e−1)
                      └ 频率项 ┘     └ 范围项 ┘
```

频率项 `f·p·(1−e)` 说"他们弃牌时我拿到多少"，只随尺度与弃牌率变；范围项 `(1−f)·b·(2e−1)` 说"被跟注时我赚还是亏"，符号**只由 `e` 与 `1/2` 的大小关系决定**。这一步是整个尺度理论的枢纽：`e > 1/2` 时它为正、越大越好，`e < 1/2` 时为负、越小越好，`e = 1/2` 时尺度完全失效。引擎实测：`p=6, b=2, f=1/4` 时 `e=1/2` 的手牌在 2bb / 6bb / 12bb 三个尺度上的增益都是 `+0.75bb`——一模一样。

### 第三步：解出临界胜率，以及符号为什么会长大反

令作差为零，得到 `e·D = N`，其中

```
D = 2b(1−f) − f·p        N = (1−f)b − f·p        e* = N / D
```

**这里就是会失败的那一步：除以 `D` 必须先问它的正负。** `D > 0` 时"下注更好"写成 `e ≥ e*`（价值区），`D < 0` 时不等号整个翻过来，写成 `e ≤ e*`（诈唬区）。`break_even_equity_to_bet` 把符号作为 `regime` 字段返回，正是为了让讲课的人没有借口把它写在脚注里。两条可以手算的边界：

```
f = b/(p+b)   （对手正好防守 MDF）  ->  N = 0  ->  e* = 0        空气无差别
f = 2b/(p+2b)                      ->  D = 0  ->  区间为 all/none   尺度单独决定，与牌力无关
```

第二条边界能取到：`p = 1, b = 1, f = 2/3` 时 `D = 0` 且 `f·p − (1−f)·b = +1/3 > 0`，返回 `all`（`tests/test_ev.py::test_when_the_fold_frequency_is_extreme_enough_equity_stops_mattering`）。

## 直觉 / Intuition

把这条等式读成两句话：

- **频率项是"能不能下"**：一个尺度是一张入场券，入场费是它所需的弃牌率。1/3 池只要 25%，2x 池要 66.67%（`python -m pokergto odds --pot 1`）。买不到这张券，这个尺度在这个局面就不存在。
- **范围项是"谁下"**：同一条尺度下，`e` 与 1/2 的关系决定你属于"越大越好"还是"越小越好"的那一半。这就是为什么"我的范围有优势所以小注"这类说法是坏的：范围优势不直接选尺度，它先决定范围里有多少手 `e > 1/2` 的牌，再由那些牌决定尺度。

心智模型：频率法是**天花板**，范围法是**住户名单**。天花板决定这栋楼能盖几层，名单决定谁住进去；把两者混为一谈，就会出现"我们的范围有优势，所以 1/3 池"这种两句正确的话拼出的错误结论。

## 算例 / Worked examples

以下每步都用 `python -c` 走 `pokergto.ev`，`f` 全部是声明输入。

**例 1 — 频率不足：`p = 6bb, b = 2bb, f = 1/4`。** `break_even_equity_to_bet` 给 `regime=above, e* = 0`。增益：`e=3/4` → `+1.125bb`；`e=1/2` → `+0.75bb`；空气 → `0.0bb`。结论：这条尺度在这个弃牌率上"人人可下"，但强牌的增益是弱牌的整倍，尺度信息全在范围项里。

**例 2 — 尺度单独决定的那行：`p = 6bb, b = 2bb, f = 0.4`。** 这正是 `1/3` 池的 `D = 0` 边界（`2·2·0.6 = 0.4·6`）。生成表里对应 `table.04-05.bet-break-even-equity` 的 `regime=all` 行。实测 `e = 0, 1/2, 3/4, 1` 四手的增益都是 `+1.2bb`——**牌力完全不参与**。这时候问"我该用强牌还是弱牌下注"是没有意义的，答案是"全都下"。

**例 3 — 区间翻号：`p = 6bb, b = 2bb, f = 0.6`。** `D = 2·2·0.4 − 0.6·6 = −2 < 0`，`regime=below, e* = 1.4`（表里显示为 `140.0000%`）。`1.4 > 1` 不是错误，而是"每一手都满足 `e ≤ 1.4`"，即全范围下注；而且排序是倒的：空气 `+2.8bb`、`e=1/2` `+1.8bb`、`e=3/4` `+1.3bb`。越弱的牌越该下注，这就是诈唬区，是分母变号的结果。

**例 4 — 同一手强牌走完整条尺度梯：`e = 3/4, p = 6bb`，每个尺度都取它自己的 MDF 弃牌率。** 增益（bb/手）：1/4 池 `0.9` · 1/3 池 `1.125` · 1/2 池 `1.5` · 2/3 池 `1.8` · 3/4 池 `1.928571` · 池底 `2.25` · 1.5x `2.7` · 2x 池 `3.0`（过牌基准 `EV(check) = 4.5`）。单调递增——这条一街模型给不出"小尺度更妙"的结论，这是本节最重要的否证，下一节 `04-02` 就是来处理它的。

## 实战牌局 / Live hands

**牌局 1（`hand.04-01-strong-hand-bigger-size`）— 现金 6 人桌，100bb。BTN 开池 3bb，BB 跟注，底池 6bb。翻牌 `Kh7s3d`，BB 过牌。Hero 拿 `AdKc`。**

- 牌力：`python -m pokergto equity "AdKc" "KJs,QJs,JTs,T9s,98s,A5s-A2s,KQo,AJo,76s" --board "Kh7s3d"` → `0.912269`（精确穷举）。`2e−1 = 0.824538 > 0`，范围项为正。
- 尺度是否存在：`python -m pokergto spr --stack 97 --pot 6` → SPR `16.167`，2x 池 = 12bb，背后还有 97bb，所以 12bb 是一个**尺度**而不是全下。
- 声明弃牌率 `f = 1/4` 下，增益：1/3 池 `+1.368403bb` · 池底 `+3.842017bb` · 2x 池 `+7.552439bb`（`EV(check) = 5.473614`）。
- 决策：大尺度。这里不是因为"BTN 有范围优势"——`table.03-01` 的 `Kh7s3d` 行确实显示 hero 胜率优势 `+0.430545`——而是因为**这一手**的 `e` 远在 1/2 之上，范围项要求把 `b` 拉大。

**牌局 2（`hand.04-01-fold-supply-flips-the-answer`）— 同一桌同一翻牌，Hero 换手持 `QdJd`，底池 6bb。**

- 牌力：同一命令换 `QdJd` → `0.347828`。`2e−1 = −0.304344 < 0`，范围项为负。
- 情形 A，`f = 1/4`：增益 1/3 池 `+0.521742bb` · 1/2 池 `+0.293484bb` · 池底 `−0.391290bb` · 2x 池 `−1.760838bb`。决策：1/3 池，且把池底那档划掉；从 1/3 池改成池底是 `0.913` bb/手的损失。
- 情形 B，`f = 0.6`（对手弃得更多，同一个尺度）：`regime=below, e* = 1.4`，四档增益全部为正，最大在最小尺度：1/3 池 `+2.104344bb` · 池底 `+1.617394bb` · 2x 池 `+0.886968bb`。
- 决策仍然是小尺度，但**理由换了**：A 里是"我的牌低于 1/2"，B 里是"弃牌率多到让整条等式翻号"。同一手牌、同一尺度，两个不同的 governing 原因——这就是本节标题问的"谁决定尺度"。

## 为何成立、何时失效 / Why it works, when it breaks

**成立的前提**：只有一条街、被跟注后直接摊牌、`f` 与 `e` 是给定的标量、弃牌的参考点为 0。这四条都在 `pokergto.ev` 的模块文档里写着。

失效的地方：

1. **`f` 不是独立于 `b` 的。** 本节的作差把 `f` 当输入。真实对局里 `f` 随 `b` 变，而引擎**无法**给出这个映射——它需要对手模型或求解结果。所以例 4 的单调递增只是"在 MDF 一致性假设下"的结论，不是"应该永远下大注"的建议。
2. **被跟注后还有后街。** `ev_bet` 里被跟注就摊牌；一条街的加法把 turn/river 的决策全压成了一个 `e`。多街版本属于 `04-04`、`04-05` 与第 06 章。
3. **防守方可以加注。** MDF 是"跟或弃"两动作下的地板；加了再加注这个选项后，总防守地板不变，但**跟注**频率可以更低（`02-03` 的失效清单第 2 条）。本节的 `f` 应读作"不面对加注的概率"。
4. **多人底池。** `f` 是**所有人**弃牌的频率。`python -m pokergto mdf --pot 10 --bet 5 --opponents 2` → 每人 42.27%，合并仍是 66.67%。频率项里的 `p` 变成要抢的整个底池，但拿到它的难度按人数相乘。
5. **范围构成不在等式里，但 `e` 的来源在。** `e` 由范围对阵范围决定，而范围是否**装得下**坚果由 `is_capped` 决定：`table.03-02` 的 `AsKsQh` 两行——hero 82 组合不封顶、villain 92 组合封顶——这类判断是范围法的输入，频率法给不出。

## 陷阱 / Common mistakes

1. **以为"对手防守 MDF，所以尺度无所谓"。** 在 MDF 一致的弃牌率下，`e = 3/4` 的手牌增益从 1/4 池的 `0.9bb` 一路涨到 2x 池的 `3.0bb`（`p = 6bb`，例 4）。*代价*：`1.875bb/手`（1/3 池 1.125 对 2x 池 3.0）。用 `python -c` 跑 `ev_bet`/`ev_check` 各一次即可复核。
2. **把"范围优势"直接翻译成"小尺度"。** 尺度方向由**这一手**的 `sign(2e−1)` 决定，不由范围平均决定。`p=6, f=1/4` 时：`e=0.35` 的手牌用 2x 池比 1/3 池少 `2.25bb/手`；`e=0.75` 的手牌用 1/3 池比 2x 池少 `3.75bb/手`。*代价*：一个尺度选错，2.25–3.75bb/手，`compare` + `regret` 直接打印。
3. **在 `regime=all` 的行里继续按牌力排序。** 1/3 池配上 `f = 0.4` 就是 `D = 0` 那行，四档牌力增益全部是 `+1.2bb`，此时"用强牌下、弱牌过"一分钱不值。*代价*：0——但你会以为自己做了区分；这条的存在说明为什么 `table.04-05` 的 `regime` 列必须先读，再谈牌力。

## 练习 / Drills

- 手算 `p = 1, b = 1/3` 时的 `D` 与 `N`，找出使 `D = 0` 的 `f`，再用 `python -m pokergto odds --pot 1` 确认 1/3 池的**所需弃牌率是 25%**——别和同一行里的 20%（跟注所需胜率＝诈唬占比）混成一体，那两个是分母不同的量。
- 用 `python -c` 对 `p=6, b=2` 扫 `f = 0.1 … 0.75`，把 `regime` 从 `above` 换到 `all` 再换到 `below` 的两个临界点写出来，与 `table.04-05` 对照。
- 说出 `e* = 200%` 和 `regime=all` 的区别：两者都是"全范围下注"，但一个是分母变号后的产物、一个与 `e` 无关。为什么表格要分成两列写？
