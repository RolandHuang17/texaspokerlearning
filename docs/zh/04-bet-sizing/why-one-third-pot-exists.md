# 小尺度为什么存在：底池比例与防守负担的换算

<!-- hands: 2 -->
<!-- terms: pot-fraction,min-bet,minimum-defense-frequency,required-equity,fold-frequency,defend,bet-size,betting-frequency,bluff-to-value-ratio,value-bet,bluff,combos,board-texture -->

## 本节目标 / Objectives

- 能把一个底池比例翻译成三件事：对手必须继续的组合数、他需要多少胜率、我的诈唬需要多高的弃牌率——全部用绝对筹码说出来。
- 能推出"这个尺度的最小可行弃牌率"与它的反面"这个局面能提供的弃牌率决定了最大的可下尺度"，并在 6bb 底池上算出具体毫米数。
- 能说出小尺度在什么条件下被排除：弃牌供给不足、整条范围都在 1/2 胜率之上、以及牌桌规则的最小下注线，并能区分哪些是引擎结论、哪些不是。

## 前置知识 / Prerequisites

- `02-03` 最低防守频率（MDF）：`MDF = p/(p+b)`，本节把它换算成组合数配额。
- `04-01` 频率法与范围法的分工：本节的"为什么存在"用的是那里的频率项，不重复推导。
- `02-04` 价值与诈唬的比例由尺度决定；`table.02-04.bluff-value-ratio` 是本节的主要证据。

## 核心原理 / The principle

小尺度不是一个"保守的选择"，它是一次换算：**`b` 越小，`MDF = p/(p+b)` 越大，对手必须继续的组合数越多，而我的诈唬所需弃牌率 `b/(p+b)` 越低。** 1/3 池之所以存在，是因为它把这三件事同时落在可用的区间上——要求对手防守 75%（994.5 个组合），却只要 25% 的弃牌率就能保本。这是 `derived` 结论，全部来自 `pokergto.odds`。

## 推导 / Derivation

符号：`p` 为下注前底池的筹码，`b` 为新增下注，比例尺度记作 `s = b/p`。

### 第一步：把尺度换算成防守配额

```
MDF = p/(p+b) = 1/(1+s)          必须继续的组合数 = 1326 · MDF
```

`1326` 不是引用来的常数，是引擎数出来的：`src/pokergto/cards.py` 的 `ALL_COMBOS` 长度 = 1326（`python -c` 验证）。于是尺度与配额的换算是一张反比表：

```
s = 1/6  ->  MDF = 6/7 = 85.71%  ->  1136.5714 组合
s = 1/4  ->  MDF = 4/5 = 80.00%  ->  1060.8000 组合
s = 1/3  ->  MDF = 3/4 = 75.00%  ->   994.5000 组合
s = 1/2  ->  MDF = 2/3 = 66.67%  ->   884.0000 组合
```

**能算出 `MDF = 75%` 的那一行，恰好就是 `s = 1/3`**：解 `1/(1+s) = 3/4` 得 `s = 1/3`。1/3 池不是习惯，是"要求四分之三防守"这条方程的解。

### 第二步：同一枚硬币的诈唬侧

```
诈唬所需弃牌率 f* = b/(p+b) = s/(1+s)
```

能防守 `1 − f*` 的对手会让空气刚好无差别（`04-01` 的第一条边界）。`s = 1/3` 时 `f* = 1/4`。这里出现本节的关键一步：**把等式反过来解 `b`**，就得到"弃牌供给决定的尺度上限"：

```
b ≤ f·p/(1−f)
```

这一步只是乘过去再除，但它假设了 `f < 1`（分母为正）——一个"对手从不弃牌"的局面里这条上限不存在，因为没有任何尺度值得用空气去下。它把"为什么是 1/3 池"变成一个可以按局面回答的问题：**当前这个局面最多能拿到多少弃牌？**

```
f = 0.20  ->  b ≤ 0.25p   （1/4 池）      f = 1/3  ->  b ≤ 0.5p
f = 0.25  ->  b ≤ 0.3333p （就是 1/3 池）  f = 0.50 ->  b ≤ 1.0p
```

### 第三步：小尺度的代价在比例里

尺度缩小，防守配额上升，但你能要求对手用多宽的范围继续，取决于他跟注的价格：`equity_needed_to_call = b/(p+2b)`，`s = 1/3` 时是 `20%`。同时你的下注范围里诈唬的比例被尺度钉死：`s/(1+2s)` = 20%，即价值:诈唬 = 4:1（`table.02-04.bluff-value-ratio` 的 1/3 池行）。**尺度越小，允许的空气越少**：1/4 池要求 5:1，1/6 池要求 7:1。小尺度因此不是"随便下一下"，它是只有一条密度足够的价值层时才付得起的入场券。

## 直觉 / Intuition

把小尺度想成一张**税单**而不是威胁：1/3 池不是在吓谁，它是在说"你必须用 994.5 个组合中的一大部分来回应我，而你回应的成本只有 2bb"。它的作用机制是配额，不是恐惧。

同一张税单的两侧都写着数字：对手被要求防守 75%，而他只要 20% 胜率就能跟——所以"他用几乎全部范围跟注"是小尺度的**预期结果**，不是它的失败。小尺度失败的唯一定义是：你以为能拿到 25% 弃牌，实际只拿到 20%。

反过来，为什么不下 1/6 池：配额涨到 85.71%，但你的诈唬配额塌到 12.5%（7:1），意味着这个尺度只能用来价值下注，空气几乎没有位置。小尺度的"小"是有下限的，下限由你自己的范围组成决定。

## 算例 / Worked examples

**例 1 — 把 1/3 池翻译成配额（`p = 6bb, b = 2bb`）。** `python -m pokergto mdf --pot 6 --bet 2` → `MDF = 0.7500`。组合数 `1326 × 0.75 = 994.5`（图见"范围图"），可弃的只剩 `331.5` 个组合。跟注所需胜率 `2/(6+4) = 20%`（`pokergto.odds#equity_needed_to_call`；同一模块的 `pot_odds(6,2) = 3` 用的是"下注前底池 ÷ 跟注额"这个约定，换成"风险 2 赢 8"的 4:1 写法，两个约定都回到同一个 20%）；我的空气需要 25% 弃牌率。

**例 2 — 弃牌供给决定尺度上限（`p = 6bb, f = 0.2`）。** 上限 `0.2/0.8 × 6 = 1.5bb`，正好是 1/4 池。实测空气 EV：1bb `+0.400000bb` · 1.5bb `0.000000bb` · 2bb `−0.400000bb` · 3bb `−1.200000bb`（`ev_pure_bluff`）。**同一个底池，弃牌率从 25% 掉到 20%，1/3 池就从保本变成每手亏 0.4bb。** 换成有牌力的手牌上限会挪动：`Td8c` 在 `Kh7s3d` 对 BB 的跟注范围胜率 `0.219128`，同样 `f = 0.2` 时上限是 `2.085128bb`（`0.3475p`）——牌力买回一点尺度。

**例 3 — 防守不足的价钱（`p = 6bb, b = 2bb`）。** 对手每少防守 10 个百分点，空气每手多赚 `Δ·(p+b) = 0.10 × 8 = 0.8bb`；少 15 个点是 `1.2bb`。实测 `ev_pure_bluff(6,2,0.35) = 0.8`，`ev_pure_bluff(6,2,0.40) = 1.2`。这条换算对小尺度同样成立，但因为 `p+b` 小，同样的错误比超池下注便宜得多（`04-03` 给出对照组：8bb 对 60bb）。

**例 4 — 多人底池把配额摊薄（`p = 6bb, b = 2bb, 2 个对手`）。** `python -m pokergto mdf --pot 6 --bet 2 --opponents 2` → 每人 `d = 0.5000`，合并 `0.7500`。**每人只需防守一半，但整桌防守的份额还是 75%。** 小尺度在多人池里的"防守负担"效应全部转移到人数上：你要求的总配额不变，而拿到 25% 全弃的难度按人数相乘。

## 实战牌局 / Live hands

**牌局 1（`hand.04-02-quota-is-not-a-hand-decision`）— 现金 6 人桌。BTN 开池 3bb，BB（Hero）跟注，底池 6bb。翻牌 `Kh7s3d`，BTN 下注 2bb（1/3 池）。Hero 拿 `QdJd`。**

- 配额：`MDF = 6/(6+2) = 75%`，即防守方（这里就是 Hero 的 BB 范围）必须有 994.5 个组合继续（`python -m pokergto mdf --pot 6 --bet 2`）。
- 单手：`python -m pokergto equity "QdJd" "AKs,AQs,ATs,KQs,AKo,AQo,99,77" --board "Kh7s3d"` → `0.161202`，低于 20% 的价格线。跟注 EV `0.161202 × 10 − 2 = −0.387980bb`。
- 但 BTN 的下注范围不只有价值牌。加上 `86o,75o` 后共 76 个组合、其中 24 个是空气（诈唬占比 `31.58%`，高于 1/3 池无差别所需的 `20%`）：`python -m pokergto equity "QdJd" "AKs,AQs,ATs,KQs,AKo,AQo,99,77,86o,75o" --board "Kh7s3d"` → `0.300926`，跟注 EV `+1.009260bb`。
- 决策：跟注，理由写清楚——**75% 是 BTN 下注范围的配额问题，`QdJd` 的 20% 是单手的价格问题**；两个数字回答两个问题。若 BTN 这里只下价值牌，同一手牌就是每手亏 `0.388bb` 的弃牌。他的空气比例是声明输入，不是本仓库测得的人群数据。

**牌局 2（`hand.04-02-third-pot-not-available`）— 同一桌、同一翻牌 `Kh7s3d`，底池 6bb。这次 Hero 在 BTN 拿 `Td8c`（对 BB 跟注范围胜率 `0.219128`），BB 过牌。判断依据是弃牌供给：`f = 0.2`。**

- 尺度上限：`0.2/0.8 × 6 = 1.5bb`。用 2bb（1/3 池）时空气亏 `0.400000bb`，而 `Td8c` 的实测增益是 `+0.038256bb`——勉强为正，但它的空间已经被 1/2 池抹掉：3bb 时 `−0.411139bb`。
- 决策：下 `1.5bb`（1/4 池，增益 `+0.262954bb`）或过牌，不要下 1/3 池去"施压"。这一手把标题的换算反过来用：**先量出弃牌供给，再决定底池比例**，而不是先选一个比例再祈祷弃牌。

## 为何成立、何时失效 / Why it works, when it breaks

**成立的前提**：单挑、一条街、`f` 是给定的声明输入、弃牌的价值就是放弃 `p`。配额换算 `1326 × MDF` 还额外假设防守方是"整个 1326 组合的范围"——真实防守范围更小，因此配额应按那个范围重算。

它失效的地方：

1. **弃牌供给低于 `b/(p+b)`。** 1/3 池要求 25%。`f = 0.2` 时它每手亏 0.4bb，尺度上限降到 1/4 池（例 2）。这是本节唯一的硬约束，且它由 `f` 决定而不是由牌面决定。
2. **整条范围都高于 1/2 胜率。** `table.03-01` 的 `Kh7s3d4c` 行给出 hero 转牌胜率 `76.9775%`；`04-01` 例 4 显示 `e = 3/4` 时每档尺度的增益单调上升，1/3 池比 2x 池少 `1.875bb/手`。**当你的范围里没有需要小尺度保护的弱牌，小尺度就失去存在理由。**
3. **防守方是多人。** 每人 50% 而不是 75%（例 4），全弃概率是各人弃牌率的乘积；把单挑配额直接套到 3 人池会超额要求防守，这条在 `07-01` 展开。
4. **牌桌规则的最小下注线。** 1/6 池在 6bb 底池是 1bb，仍然合法；但在 1bb 底池里 1/3 池可能低于最小下注。**这条不是引擎结论**：本仓库的 `pokergto` 没有下注规则约束模型，它是牌桌规则（`min-bet`），标记为 `reference` + **未核验**。
5. **"干面就打 1/3 池"这类牌面质地经验。** 引擎里没有把 `board-texture` 映射到可得弃牌率的任何计算物，因此本节不给出任何"哪类牌面打小池"的结论。能核验的只有上面第 2 条那种通过胜率与封顶状态传导的关系。凡读到"三张同花面不打小注"之类说法，一律按 **未核验** 处理。

## 陷阱 / Common mistakes

1. **把 1/3 池当成万能持续下注尺度。** 它是 `f ≥ 25%` 的函数，不是默认值。*代价*：弃牌供给只有 20% 时，空气下 2bb 每手 `−0.4bb`；换成 1.5bb 是 `0.0bb`（例 2）。
2. **用 MDF 决定一手牌要不要跟。** `QdJd` 那手：按价格算该弃（`−0.387980bb`），按对手的 4:1 结构算该跟（`+1.009260bb`），而 75% 的配额既不告诉你第一件事也不告诉你第二件。*代价*：`1.009260bb/手`（该跟而弃）或 `0.387980bb/手`（该弃而跟），两个方向都来自牌局 1。
3. **以为小尺度"风险小所以安全"。** 你冒的筹码确实小，但你放弃的是强牌的全部价值项：`e = 3/4, p = 6bb, f = 1/4` 时 1/3 池增益 `1.125bb`，2x 池增益 `3.0bb`。*代价*：`1.875bb/手`——小尺度对强牌并不便宜，它只是对弱牌便宜。

## 练习 / Drills
