# 保护还是价值：一张牌如何改变下注的理由

<!-- hands: 2 -->
<!-- terms: protection-bet, semi-bluff, value-bet, equity-realization, flush-draw, outs, equity, showdown, fold-equity, bet-size -->

## 本节目标 / Objectives

- 能用 `hand_equity` 与 `draw_probability` 把"过牌让对手免费看一张牌"这件事算成一个数：对手补牌的成牌率、成牌后他拿走的底池份额、你在这条分支上的胜率。
- 能验证并解释这条恒等式 `p·e(成牌) + (1 − p)·e(未成牌) = e(现在)`，并由此说明"否认胜率"本身在双方都过牌到摊牌的模型里值 0 个筹码。
- 能把 `EV(bet) − EV(check)` 写成 `价值项 + 保护项 + 弃牌项` 三项，并明确指出只有保护项依赖对手后续街的策略输入 `β`，因此"保护收益"作为一个单独的数字在本仓库不可核验。

## 前置知识 / Prerequisites

- `01-03` 补牌数与精确成牌率（以及"未观测牌是 45 张还是 47 张"这个坑）。
- `02-06` `EV(bet) = f·P + (1 − f)·(e(P + 2B) − B)` 与 `EV(check) = e·P`；`02-07` 薄价值。
- `01-06` 胜率实现（EqR）的概念；`adr/0002`：没有锚点的模型不许当结论。

## 核心原理 / The principle

**"保护"不是一个额外的收益项，它是同一个期望值差里依赖对手未来动作的那一部分。** 本仓库能算的是三件：

1. 对手成牌的概率 `p`（`draw_probability`，精确枚举，不是二四法则）。
2. 他成牌之后你在摊牌上的胜率 `e(成牌)`，以及成牌/未成牌两支加权后必须回到当前胜率 `e(现在)` 这一恒等式。
3. 把 `EV(bet) − EV(check)` 拆成三项：`B·(2e(现在) − 1)`（价值项）+ `B·β·p·(1 − 2e(成牌))`（保护项）+ 弃牌项 `f·(P − EV(跟注))`。

其中 `β` 是"他成牌后在下一条街下注的频率"。**这个形状的跨街频率，本仓库有一个博弈算得出来**：Leduc 有两条下注街，生成物里第二街是按"自己的牌 + 两张公共牌"索引的（`data/gen/solver/leduc.json`）。算不出的是**上面这手牌**的 `β`——Leduc 的牌组、每街一个尺度、没有牌面发展，都不是这个翻牌，而本仓库没有解过任何翻后 hold'em 博弈。所以保护项在这里仍然只能是 `β` 的函数，不能是一个数。

## 推导 / Derivation

记：底池 `P`，我眼下下注 `B`，对手面对 `B` 的弃牌率 `f`；我"现在就把钱推进去"时的胜率 `e₀ = e(现在)`；下一条街他成牌的概率 `p`，成牌后我的胜率 `e_hit`，未成牌后我的胜率 `e_miss`。

**第一步：胜率是鞅。** 由全期望，对每一条街的每一张牌取平均：

```
p·e_hit + (1 − p)·e_miss = e₀
```

这不是近似，是枚举的必然结果；`AcAd` 对 `QhJh`（`9h5h3d`）上它精确成立：`e₀ = 61/99 = 61.6162%`，`e_hit = 7/198 = 3.5354%`，`e_miss = 67/88 = 76.1364%`，`p = 1/5`，回代得 `0.6161616161616161`，与 `e₀` 到 1e-16 一致。

**这条恒等式的后果很硬**：如果"我过牌"这一支的模型是"他也过牌、双方看到摊牌"，那么 `EV(check) = e₀·P`，而我下注被跟的期望是 `e₀(P + 2B) − B`。两者相减：

```
EV(bet) − EV(check) = B·(2e₀ − 1)      (令 f = 0)
```

里面**没有任何一项叫"保护"**。否认对手看一张免费牌并没有赢到钱——那张牌他本来也平均赢不到更多。传统说法"下注是为了保护我的胜率"在这个模型里等于零。

**第二步：把保护项请出来。** 它出现的唯一方式是：过牌之后对手**能看牌再决定**。把这件事参数化，`β = P(他成牌后下注)`，未成牌时他过牌（本节的教学模型），我面对转牌下注跟注。于是

```
EV(check) = (1 − p)·e_miss·P + p·[ β·( e_hit(P + 2B) − B ) + (1 − β)·e_hit·P ]
```

用第一步的恒等式把 `P` 项全部合并（`(1−p)e_miss + p·e_hit = e₀`），剩下的只差一个括号：

```
EV(bet) − EV(check) = B·[ (2e₀ − 1) − β·p·(2e_hit − 1) ]      (f = 0)
                    = B·(2e₀ − 1) + B·β·p·(1 − 2e_hit)
```

`β = 0` 时回到第一步，保护项精确消失。**保护项 = `B·β·p·(1 − 2e_hit)`**：它随下注尺度 `B` 线性、随成牌率 `p` 线性、随"成牌后我有多落后"（`1 − 2e_hit`）增长，而 `β` 是对手策略。

**第三步：这条式子否掉的两句口诀。**

- "落后的牌也要下注保护它"：`e₀ < 1/2` 时价值项为负，保护项要翻盘必须 `β·p·(1 − 2e_hit) > 1 − 2e₀`。可听牌自己那一侧 `e_hit` 接近 1（`1 − 2e_hit` 变负），保护项**恒为负**：`QhJh` 的保护项在 `B = 5, β = 1` 时是 `−0.929293`。所以听牌下注不是保护，是半诈唬，它靠的是弃牌项。
- "保护要下大注才有效"：`B` 只在保护项外乘一次，符号与 `B` 无关。真正限制 `B` 的是筹码上限（`table.04-03.size-ceiling-by-stack`）和 `f` 随尺度上升后带来的价值损失——不是"保护"这个理由。

## 直觉 / Intuition

把免费牌看成对手手里的一张期权：**期权本身不改变期望胜率（鞅），它改变的是"谁能在好消息之后要钱"。**

所以你过牌让出去的不是胜率，是选择权。下注把选择权买回来：他现在就得为那张牌付 `B`，而不是先看牌、再决定要不要付。这也解释了为什么"保护"总在半成半空的牌面上被挂嘴边——那里的下一张牌对双方都改变很大（`1 − 2e_hit` 接近 1），而对已经定型的牌面（河牌）它是 0：**河牌上根本没有保护，只有价值与诈唬。**

## 算例 / Worked examples

**例 1 — 一副听牌的全部可算数字（`9h5h3d`，`AcAd` 对 `QhJh`）。**

| 量 | 数值 | 来源 |
|---|---|---|
| 未观测牌 | 45 | 7 张已知（2 + 2 + 3），不是 47 |
| 转牌成牌率 `p` | 20.00%（`9/45`） | `draw_probability(9, 45, 1)` |
| 到河牌成牌率 | 36.36%（`9/45` 两张） | `draw_probability(9, 45, 2)` |
| 现在胜率 `e₀` | 61.6162%（`61/99`） | `poker equity "AcAd" "QhJh" --board "9h5h3d"` |
| 成牌后我的胜率 `e_hit` | 3.5354%（`7/198`） | 9 张红桃转牌的期望胜率平均 |
| 未成牌后我的胜率 `e_miss` | 76.1364%（`67/88`） | 36 张非红桃转牌的平均 |
| 他成牌后拿走的底池份额 | 96.4646% → `9.6465` 个筹码（`P = 10`） | `1 − e_hit` |

若按 47 张算（只扣除自己与公共牌），`p = 19.1489%`、到河 `34.9676%`——这正是 `table.01-03.draw-probability-exact-vs-rule` 那一行的口径。**同一手牌，47 与 45 差 0.85 个百分点**，这就是为什么本节把未观测牌数写成输入而不是靠记忆。

**例 2 — 三项分解（`P = 10`，转牌下注尺度与翻牌相同 = `B`，`β = 1`）。**

| `B` | 价值项 `B(2e₀ − 1)` | 保护项 `Bβp(1 − 2e_hit)` | 合计 `EV(bet) − EV(check)` |
|---|---|---|---|
| 1/3 池（3.333） | 0.774411 | 0.619529 | 1.393939 |
| 1/2 池（5） | 1.161616 | 0.929293 | 2.090909 |
| 底池（10） | 2.323232 | 1.858586 | 4.181818 |

`β = 0` 时三行的保护项全是 `0.000000`，合计退回价值项。`β = 1/2` 时保护项减半（1/2 池那行是 `0.464646`，合计 `1.626263`）。**这就是"保护收益"的真面目：它不是一个数，是一条关于 `β` 的直线。**

**例 3 — 弃牌项（同一手牌，`B = 5, f = 1/3`）。** `EV(bet) = 8.215488`、`EV(check) = 5.232323`（`β = 1`），差 `2.983165`。相对 `f = 0` 的 `2.090909`，弃牌支只加了 `0.892256` 个筹码，而不是 `f·P = 3.3333`——因为弃牌支省下的是"被跟注会输掉的那部分"，`f·(P − EV(跟注))`。把 `f·P` 直接当弃牌赢率加上去，是本节最容易犯的算术错。

**例 4 — 补牌数几乎减半，保护项却不到一半（`Kd9c4s`，`AcAd` 对 `QhTh`，4 张开张顺子）。** `p = 4/45 = 8.8889%`、`e₀ = 81.3131%`、`e_hit = 0.000000`、`e_miss = 89.2461%`，`B = 5, β = 1` 时保护项是 `0.444444`，合计 `3.575758`。与例 2 的 9 张听牌比，`p` 之比是 `9 : 4 = 2.25`，而保护项之比是 `2.09`——差的来源是 `1 − 2e_hit` 不同（`0.929293` 对 `1.000000`）。**保护项不是"补牌数"的单调函数，它同时看成牌后你有多落后**，而"多落后"要用枚举而不是用心跳。

## 实战牌局 / Live hands

**牌局 1（`hand.04-06-flushdraw-protection`）— 翻牌 `9h5h3d`，底池 10 bb，我方 `AcAd`，对手 `QhJh`（同花听牌 + 两张高牌），估 `f = 1/3`（1/2 池的 MDF 补）。**

- 可算的量：`p = 20.00%`、`e₀ = 61.6162%`、`e_hit = 3.5354%`、`e_miss = 76.1364%`；他成牌后从 `P = 10` 的底池里拿走 `9.6465` bb。
- 价值项 `1.161616`，保护项 `β·0.929293`，弃牌支 `0.892256`（`f = 1/3` 时）。
- 决策：**下注 1/2 池**。理由要按可核验的顺序写：先说 `EV(bet) = 8.215488 > EV(check) = 5.232323`（差 `2.983165` bb），再说这差里有多少来自对手策略（`β = 1` 时 `0.929293` bb，占 `31.2%`），最后承认 `β` 未核验。
- 如果对手是"成牌也不下注、错过也不下注"（`β = 0`）：`EV(check) = 6.161616`，差缩到 `2.053872`，其中保护贡献 `0`。**同一个动作、同一手牌，"保护"的贡献从 31.2% 掉到 0%——所以它是理由，不是账。**

**牌局 2（`hand.04-06-draw-not-protection`）— 同一翻牌 `9h5h3d`，底池 10 bb，视角换成对手 `QhJh`（他才是落后的一方），考虑"要不要为了保护我的听牌权益下注"。**

- 他这一侧：`e₀ = 38.3838%`、`e_hit = 96.4646%`、`1 − 2e_hit = −0.929293`。价值项 `B(2e₀ − 1) = 5 × (−0.232323) = −1.161616`，保护项 `Bβp(1 − 2e_hit) = −0.929293`（`β = 1`）。两项都负。
- 结论：**"保护"不可能是他下注的理由**，任何把它当理由的写法都是错的。他的下注是半诈唬，靠的是 `02-05` 的弃牌支：`f` 达到 `B/(P+B) = 1/3` 时纯空气保本（`ev_pure_bluff`），而他手里还有 20.00% 的成牌率把这条线拉低——这正是 `02-04` 半诈唬比空气便宜的原因。
- 代价（把保护当账会算错的地方）：若他按 `β = 1` 的保护项当成正收益 `+0.929293` 来决策，就会把 `−0.929293` 读成 `+0.929293`，动作期望值差 `1.858586` bb/手，方向完全相反。
- 教学落点：保护项的符号由 `1 − 2e_hit` 决定，也就是说**只有"成牌后我落后"的那一方才有保护可言**。

## 为何成立、何时失效 / Why it works, when it breaks

**成立的前提**：`p`、`e_hit`、`e_miss`、`e₀` 由精确枚举得到（无蒙特卡洛误差）；`f` 与 `β` 是声明的输入；过牌一支假定"未成牌他就过牌、成牌他就下注"这个教学分支；我面对转牌下注跟注；一张牌到转牌。

**失效之处**：

1. **`β` 不可算。** 它是"对手在成牌之后、无额外信息条件下是否开火"的频率，需要两街解。本仓库没有（`docs/development/solver-proof-policy.md`：`PUBLISHED_PROOFS` 只有 Kuhn 与五个单街玩具）。保护项在这里只能写成 `β` 的线性函数；任何"保护值 X bb/100"的数字都是外部断言，须标 `reference` + UNVERIFIED。
2. **鞅只在"同一副牌、同样的下一张牌"下成立。** 若下注本身改变成牌分布（例如逼出更窄的跟注范围，`e₀` 换人算），恒等式仍对，但 `e₀` 的定义域变了。
3. **河牌上保护项恒为 0。** `p = 0`（没有下一张牌），只剩价值项与弃牌项。把河牌下注叫"保护"是术语错误。
4. **多人底池。** 成牌率与"所有人一起弃"的 `f` 都要按人数改（`pokergto.odds.defense_frequency_multiway`）；`07-02` 之后重开。
5. **它没有把"对手成牌后加注"这一支算进来**，只算了跟注。加注会改变 `e_hit` 一支的价值，但同样需要 `β` 型输入。
6. **不引入任何"保护指数"。** `src/pokergto/theory/__init__.py` 记录了三个模块为何被删：它们用编造的指数产出看似精确的数字。本节宁可用一个未定的 `β`，也不写一个假定的幂。

## 陷阱 / Common mistakes

1. **把"否认对手看免费牌"当成赢到的钱。** 鞅恒等式说这是 0（`β = 0` 时合计退回价值项）。
   *代价*：`β = 1` 的教学分支里保护项只有 `0.929293` bb/手（1/2 池），把它当成"我下注赚的都是保护"会把 31.2% 说成 100%。
2. **把 `f·P` 当弃牌支的全部贡献。** 弃牌支省下的是"会被跟注时输掉的部分"。
   *代价*：例 3 里 `3.3333` 对实际 `0.892256`，高估 `2.44` bb/手。
3. **给落后的一方派"保护"任务。** 落后者的 `e_hit` 更高，保护项为负（例 2 牌局）。
   *代价*：符号一错，动作期望值差 `1.858586` bb/手且方向相反；这正是把半诈唬讲成保护性下注的后果。
4. **用记忆里的成牌率代替枚举。** 45 与 47 之差、以及二四法则在 12 张补牌上的误差（`table.01-03.draw-probability-exact-vs-rule`：精确 `44.9584%` 对法则 `48%`，差 3.04 个百分点）。
   *代价*：`p` 被高估时保护项被高估，比例同步，方向不变——但结论"值不值得为此多下一注"会翻。

## 练习 / Drills

- 用例 1 的四个数验证鞅：`p·e_hit + (1 − p)·e_miss` 与 `e₀` 是否相等（答案：`0.6161616161616161` 两边一致）。
- 令 `β = 1/3`、`B = 1/2 池`、`P = 10`，自己算三项并求和（答案：价值项 `1.161616`、保护项 `0.309764`、合计 `1.471381`）。
- 找一手 `e₀ = 1/2` 的对抗范围（例如自己构造 `poker equity`），说明此时价值项为 0、保护项仍为正——这就是"保护性下注"能独立成立的唯一牌力点。
- 用 `draw_probability(9, 45, 2)` 与 `draw_probability(9, 47, 2)` 算出两个口径差（`36.3636%` 对 `34.9676%`），并解释为什么"两张已知对手手牌"要扣掉。
