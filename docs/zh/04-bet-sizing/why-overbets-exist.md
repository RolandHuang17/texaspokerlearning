# 超池下注为什么存在：坚果容量撑起尺度

<!-- hands: 2 -->
<!-- terms: overbet,pot-fraction,capped-range,the-nuts,capacity,nut-advantage,spr,effective-stack,bet-size,minimum-defense-frequency,exploitability,bluff,combos -->

## 本节目标 / Objectives

- 给定底池与剩余筹码，能先判断"2x 池"这个尺度是否存在，再谈它该不该用；能用 `table.04-03.size-ceiling-by-stack` 指出这条线在哪里从尺度变成全下。
- 能算出超池尺度对防守方施加的最低防守频率（MDF）、少守 10 个百分点的筹码代价，并说明为什么同一个错误在超池上比在 1/3 池上贵一个数量级。
- 能用组合数与封顶判断（`is_capped`）说明一条范围要拿出多少空气才撑得起 2x 池，以及拿不出来时为什么这个尺度不存在。

## 前置知识 / Prerequisites

- `04-02` 尺度与防守负担的换算，以及上限式 `b ≤ f·p/(1−f)`。
- `02-03` 最低防守频率（MDF）：`MDF = p/(p+b)`；尺度越大，防守配额越小。
- `03-01` 坚果优势（nut-advantage）与容量（capacity）：谁能在钱进池时拿着最好的牌，是本节的准入条件。

## 核心原理 / The principle

超池下注存在，是因为**价值项随 `b` 线性增长，而它索取的防守配额随 `b` 线性下降**；但它同时是尺度梯上最常被筹码上限砍掉的一档：**2x 池是 `2p` 个筹码，背后至少有 `2p` 它才存在（恰好 `2p` 时它同时就是全下），要有 `S > 2p` 它才是一个可选择的尺度。** 支撑这条尺度的是范围的坚果容量——`table.03-02.capped-range-check` 里不封顶的那一侧才付得起它索取的空气比例。这是 `derived` 结论：筹码部分来自 `pokergto.spr`，比例部分来自 `pokergto.odds`，容量部分来自 `pokergto.theory.range_advantage`。

## 推导 / Derivation

符号沿用前两条课：`p` 下注前底池、`b` 新增下注、`f` 对手全弃的频率（声明输入）、`e` 钱进池后的胜率、`S` 行动者背后的有效筹码（effective-stack）。

### 第一步：存在性先于最优性

一个尺度首先是筹码：`b ≤ S`。定义"最大可下注 ÷ 底池" = `S/p`，它就是 SPR。于是

```
2x 池存在        <=>  2p ≤ S    <=>  SPR ≥ 2      （取等号时它同时就是全下）
池底之后仍有一次池底  <=>  S − p > p  <=>  SPR > 2
```

`table.04-03.size-ceiling-by-stack` 把这条换算成八行筹码表（底池固定 6bb）。它最后一列 `池级下注即全下` 用的是生成器的判据 `stack <= 2 * pot`，即 `SPR ≤ 2`：表里剩 8bb 与 10bb 的两行为真，意思是**下完一个池底之后剩下的钱已经不够再一次池底**，这条街要决定的其实不再是"下多少"而是"是否套池"。MDF 那条公式在这两行仍然成立，但尺度梯上的档位不再是可自由选择的变量——`table.02-03.mdf-vs-sizing` 的 1x pot 行在这里描述的是一个准全下动作。

### 第二步：超池为什么划算（价值项是线性的）

`04-01` 的闭合式里，被跟注那一项是 `(1−f)·b·(2e−1)`：`e > 1/2` 时它随 `b` 线性增长。所以同一手强牌，尺度翻倍，增益也差不多翻倍——`e = 3/4` 在 6bb 底池、各档自己的 MDF 弃牌率下：1/3 池 `1.125bb`、池底 `2.25bb`、2x 池 `3.0bb`。

防守侧同步变化，而且是**下降**：`MDF = 1/(1+s)`，`s = 2` 时只有 `33.33%`（442 个组合，见"范围图"）。把少守 Δ 个百分点的价钱写成 `Δ·(p+b)`：`s = 1/3` 时 `p+b = 8bb`，`s = 2` 且 `p = 20bb` 时 `p+b = 60bb`。**同一个 13.33 个百分点的防守漏洞，在 1/3 池上让空气赚 `1.066667bb`，在 2x 池上让空气赚 `8.000000bb`——7.5 倍。** 这就是超池下注的威胁性所在：它不是靠"吓跑人"，而是靠"你不敢不跟"。

### 第三步：容量——谁能付这条尺度的空气税

`02-04` 的比例式给出下注范围里的诈唬占比 `s/(1+2s)`：`s = 1/3` 是 20%，`s = 2` 是 **40%**（价值:诈唬 1.5:1，`table.02-04.bluff-value-ratio` 末行）。也就是说，越大的尺度要求的空气**越多**，而不是越少：每 3 个价值组合要配 2 个诈唬组合。空气本身是亏的，只有当它背后站着足够多"能赢下大注"的牌时，这个比例才不会被加注拆穿——这正是坚果容量的作用：`is_capped` 为假的一侧才拿得出 40% 的空气，因为它同时拿得出 16 个坚果级组合。引擎实测（4 张牌面 `AsKsQhJd`，范围为讲解输入）：

```
python -c "..."  ->  villain capped True   hero capped False
```

反过来说："超池下注极化、所以全是坚果"这句流行话是半个错误——极化的是**比例**，40% 是空气，60% 才是坚果与强牌。

## 直觉 / Intuition

把尺度梯想成一栋楼：1/3 池是地基，它要求对手防守 75%（994.5 个组合），代价是你只能带 20% 的空气上楼；2x 池是顶楼，它只要求 33.33%（442 个组合），但要求你带 40% 的空气，而且**必须先确认楼还没到屋顶**——剩余筹码 `S` 就是屋顶。

三条直觉钉子：

- 尺度的天花板是筹码，不是勇气：`SPR < 2` 时，"2x 池"这一档在物理上不存在。
- 大尺度惩罚的是防守频率错误，不是牌力错误：它的价钱按 `Δ·(p+b)` 结算，`p+b` 越大越贵。
- 空气比例是入场券：拿不出 40% 的空气（或者拿不出撑起它的坚果组合），这个尺度对你就是空的。

## 算例 / Worked examples

**例 1 — 存在性检查（底池 6bb）。** `python -m pokergto spr --stack 8 --pot 6` → SPR `1.333`，全下所需胜率 `0.3636`；`python -m pokergto mdf --pot 6 --bet 8` → `MDF = 0.4286`。这里根本没有 2x 池（`2p = 12bb > 8bb`），最大尺度是 8bb = 1.3333 池，而且它就是全下。若对手错误地套用尺度梯上 2x 池那行的 `MDF = 33.33%`，他少守的 `9.5238` 个百分点按 `Δ·(p+b)` 结算：`0.095238 × 14 = 1.333333bb`，实测 `ev_pure_bluff(6,8,2/3) = 1.333333`。**用一个不存在的尺度的数字去防守，等于每次白送 1.33bb。**

**例 2 — 合法的超池值多少（底池 20bb、剩 60bb、`e = 0.919545`）。** `python -m pokergto spr --stack 60 --pot 20` → SPR `3.000`，所以 2x 池 = 40bb 是一个尺度（不是全下，下完还留 20bb）。各尺度取自身 MDF 弃牌率时的增益（bb/手）：1/3 池 `4.597725` · 池底 `9.195450` · 2x 池 `12.260600`；`compare` + `regret` 给 `1/3 池` 相对最优的遗憾是 `7.994944bb/手`。**这一手里"下小一点更安全"的代价是每手 8bb。**

**例 3 — 防守不足的价钱随尺度膨胀（底池 20bb，2x 池 = 40bb）。** `python -m pokergto mdf --pot 20 --bet 40` → `MDF = 0.3333`。防守 20%（少 13.33 个百分点）时空气 EV `ev_pure_bluff(20,40,0.8) = 8.000000bb`；正好守到 33.33% 时 `0.000000bb`（无差别）；守到 40%（弃 60%）时 `−4.000000bb`——多守是对手的利润，不是你的保险。

**例 4 — 诈唬侧的门票与区间翻号（`p = 1, b = 2`）。** 空气保本要求 `f ≥ b/(p+b) = 66.67%`；由 `b ≤ f·p/(1−f)` 反解，`f = 0.5` 时尺度上限只有 1x 池。再往上：`D = 2b(1−f) − f·p` 在 `f = 0.8` 归零，`break_even_equity_to_bet` 在 `f = 0.9` 才给出 `regime=below, e* = 1.4`（实测：`f = 0.75 → above, e* = −100%`；`f = 0.8 → all`；`f = 0.9 → below`）。**超池尺度要进入"越弱越该下注"的区间，需要对手弃掉 80% 以上——比 1/3 池的同一件事（`f = 0.4`）难得多。** 这条也解释了为什么 `table.04-05.bet-break-even-equity` 的 2 pot 段里全是 `above`：在 25%–75% 的声明弃牌率里它一次都没有翻号。

## 实战牌局 / Live hands

**牌局 1（`hand.04-03-the-size-that-does-not-exist`）— 现金 6 人桌，有效筹码 15bb。BTN 开池 3bb，BB 跟注（底池 6bb）。翻牌 `Kh7s3d`，BTN 下 2bb，BB 跟注（底池 12bb），双方各剩 10bb。转牌 `4c`。BTN（Hero）拿 `AdKc`。**

- 存在性：`python -m pokergto spr --stack 10 --pot 12` → SPR `0.833`，全下所需胜率 `0.3125`。2x 池要 24bb，而背后只有 10bb——**这个尺度不存在**；最大可下注 10bb = `0.8333` 池，且它就是全下。
- 真实数字：`python -m pokergto mdf --pot 12 --bet 10` → `MDF = 0.5455`，所需弃牌率 `45.45%`，而不是尺度梯上 2x 池那行的 `66.67%`。
- 牌力：`python -m pokergto equity "AdKc" "KJs,QJs,JTs,T9s,98s,A5s-A2s,KQo,AJo,76s" --board "Kh7s3d4c"` → `0.953095`，远高于全下所需的 `31.25%`。
- 决策：全下 10bb。如果 BB 按"2x 池"的 33.33% 配额来防守这条其实只有 0.8333 池的线，他少守 `21.2121` 个百分点，空气每次白拿 `0.212121 × 22 = 4.666667bb`（实测 `ev_pure_bluff(12,10,2/3) = 4.666667`）。

**牌局 2（`hand.04-03-legal-overbet-on-a-capped-line`）— 单挑，深筹码。翻牌前 3-bet 后底池 20bb，双方各剩 60bb。转牌 `AsKsQhJd`。Hero 拿 `Td9d`（顺子 A，此刻的坚果），对手范围按讲解输入取 `98s,76s,54s,65s,K9s,K8s,Q9s,J9s`。**

- 牌力：`python -m pokergto equity "Td9d" "98s,76s,54s,65s,K9s,K8s,Q9s,J9s" --board "AsKsQhJd"` → `0.919545`；不是 100%，因为河牌任何黑桃会给对手同花。
- 容量：`is_capped` 对这条防守线在 `AsKsQhJd` 上返回 `True`（对手范围里连顺子的形状都没有），hero 一侧返回 `False`。**能威胁坚果的一侧才付得起 2x 池的 40% 空气。**
- 决策：下 40bb（2x 池）。增益对比（各尺度自取 MDF 弃牌率）：1/3 池 `4.597725bb` · 池底 `9.195450bb` · 2x 池 `12.260600bb`；把这条线改成 1/3 池要付出 `7.994944bb/手` 的遗憾值。
- 对手这边的算术：`MDF = 20/60 = 33.33%`，即他 1326 个组合里最多只能弃 884 个（442 个继续）；他若弃 80%，空气在这里每手 `+8.000000bb`。

## 为何成立、何时失效 / Why it works, when it breaks

**成立的前提**：`S ≥ 2p`（尺度存在）、`e > 1/2` 的那一段范围足够宽（价值项吃得到线性增长）、下注范围能拿出 40% 的空气且背后有坚果组合撑着、对手会用接近 MDF 的频率防守（否则本节谈的是剥削而非结构）。

失效清单：

1. **`SPR < 2`。** `table.04-03.size-ceiling-by-stack` 的前两行（剩 8bb、10bb）里 2x 池直接不存在；`SPR ≤ 2` 时 `pot_size_bet_commits` 为真，池底之后已无第二次池底，尺度选择变成套池选择。
2. **封顶的一侧。** `is_capped` 为真时，你的范围最多只能拿 1.5:1 的比例配 40% 空气里的那部分价值牌，威胁不可信。`table.03-02.capped-range-check` 的 `AsKsQh` villain 行就是这种形状（封顶 92 组合，最强手只是一对）。
3. **弃牌供给不够。** 空气在 2x 池上要 66.67% 弃牌率；`f = 0.5` 时上限是 1x 池，硬下 2x 池的空气 EV 是 `−10.000000bb`（`p=20`）。这是 `04-02` 例 2 的同一把尺子，只是这次量出的是"不能这么下"。
4. **加注选项。** 本节的模型里防守方只能跟或弃。真实超池尺度面对的加注威胁更大，而大注恰恰是给加注留的价位——引擎里没有再加注的一街模型，这部分结论**未核验**。
5. **风险厌恶。** 钱进池的决策在锦标赛里不是线性的，`all_in_equity_needed` 给的胜率门槛要按 ICM 折算；第 12 章处理。

## 陷阱 / Common mistakes

1. **喊出一个筹码不支持的尺度。** 底池 12bb、剩 10bb 时"2x 池"不存在；照 2x 池那行的 33.33% 去防守，等于让空气每次拿 `4.666667bb`。*代价*：`4.666667bb/手`（牌局 1）。
2. **以为超池下注是"全是坚果"。** `table.02-04.bluff-value-ratio` 末行写着 2x 池要求价值:诈唬 = 1.5:1，即 40% 是空气；*代价*：拿不出这 40% 的范围去下 2x 池，对手只需弃掉 66.67% 就让空气保本，而你少下的那部分价值是 `7.994944bb/手`（例 2 的遗憾值）。
3. **把小尺度的防守错误价格直接搬到超池上。** 同样少守 13.33 个百分点：1/3 池（`p=6, b=2`）空气 `+1.066667bb`，2x 池（`p=20, b=40`）空气 `+8.000000bb`。*代价*：`6.933333bb/手` 的认知差——按 8 倍的价钱决定你的防守频率，而不是按训练时习惯的 8bb。
