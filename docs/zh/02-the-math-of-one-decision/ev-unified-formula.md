# 一套符号管住所有动作：跟注、下注、加注与全下

<!-- hands: 2 -->
<!-- terms: expected-value, ev-decomposition, fold-equity, call, bet, raise, check, shove, regret, equity -->

## 本节目标 / Objectives

- 能用一个模板写出翻后任何动作的期望值，并把跟注、过牌、下注、加注、全下都当成它的特例，而不是五条各自独立的公式。
- 能说清为什么"底池已经投进去的钱"不该出现在任何一条式子里，以及忘了这条约定会重复计价多少。
- 会用引擎并排算出几个候选动作的期望值与遗憾值，并说清遗憾值就是训练器报的那个量。

## 前置知识 / Prerequisites

- `02-01` 保本百分比；`02-05` 弃牌赢率（本节直接拿它的模板当主语）。
- `01-03` 胜率的定义 `e = P(赢) + ½·P(平分)`。

## 核心原理 / The principle

只有一个式子：

```
EV(bet) = f·P + (1 − f)·(e·(P + 2B) − B)
```

三个记号按 `pokergto/ev.py` 的约定：`P` 是**我方投入之前**池里的钱，`B` 是我方这次要投进去的钱，`f` 是所有对手都弃牌的概率，`e` 是钱进池之后我方的胜率。

约定本身同样重要，而且只有一条：**弃牌 = 0**。你已经投进池的钱在"弃牌"和"继续"两个分支里都拿不回来，所以在任何差值里它都会抵消，永远不该出现在式子中。这条约定写在一个显式返回 `0.0` 的函数里（`ev_fold`），不是为了好看，是因为不写出来的学习者会把自己的旧投入重复算进期望值——那是自学复盘里最常见的算术错误。

## 推导 / Derivation

五个动作，同一个式子。

**弃牌（`ev_fold`）**：定义上的 0，是本节所有比较的基准。

**跟注（`ev_call`）**：`f = 0`（没人会因为你的跟注而弃牌），于是模板塌成

```
EV(call) = e·(P + 2B) − B
```

这就是 `02-02` 那条"最终池子 `P + 2B`，你出 `B`"的来源；令它为 0 就得到所需胜率 `B/(P+2B)`。数值核对：`P = 10, B = 5, e = 0.541414` → `5.82828`，与 `ev_bet(10, 5, 0, e)` 完全相同。

**过牌（`ev_check`）**：`B = 0`，而且没人能被过牌打跑，所以 `f` 这一支不存在，剩下"免费看到摊牌"：

```
EV(check) = e·P
```

**下注（`ev_bet`）**：模板原样。两支的权重复核：`f + (1 − f) = 1`，这正是期望值的定义。

**全下（`ev_shove`）**：模板里 `B = 后手筹码`。引擎把它单列成一个入口点，是因为短码锦标赛里 `B` 根本不是自由变量；数值上两者一模一样：`ev_bet(12, 15, 0.4, e)` 与 `ev_shove(12, 15, e, 0.6)` 都等于 `9.443633`。

**加注**：这是唯一需要动手改记号的动作，而且它不改式子，只改 `P` 和 `B` 的取值。设底池 `P`，对手下注 `B₀`，你加到 `R`。

- 对手弃牌时你收走的是 `P + B₀`（含他那注）。
- 他跟注时他会补齐差额 `R − B₀`，最终池子 `P + 2R`，你的净投入是 `R`。

所以直接从定义写：

```
EV(raise to R) = f·(P + B₀) + (1 − f)·(e·(P + 2R) − R)
```

它仍然是同一个模板——只要把加注看成"先跟 `B₀`、再把多出来的部分投进已经配平的池子"，也就是代入

```
P₁ = P + 2B₀,   B₁ = R − B₀,   EV = ev_bet(P₁, B₁, f, e) − B₀
```

末尾那个 `− B₀` 是把基准从"我已经跟了"挪回"我还没动手"。用 `P = 10, B₀ = 5, R = 20, f = 0.3, e = 0.541414` 走一遍：

| 算法 | 结果 |
|---|---|
| 直接代定义式 | `9.44949` |
| 模板 + 代入 `P₁ = 20, B₁ = 15`，再减 `B₀` | `9.44949` |
| 偷懒：直接 `ev_bet(10, 20, 0.3, e)` | `7.94949` |

第三条错在把对手那 `B₀` 从弃牌支里漏掉了，误差恰好是 `f·B₀ = 0.3 × 5 = 1.5`。**加注从来不是一条新公式，它只是同一公式换了参量。**

## 直觉 / Intuition

"不同场合要用不同公式"这个感觉，来自记号而不是来自博弈。真实的牌局里只发生两件事：对手会不会弃牌，以及不弃牌的时候钱进池后你占多少。所有动作的差别，只是这两个量在你手上是已知的还是要估的：

- 跟注：没有弃牌支，只剩摊牌支。
- 下注：两支都有。
- 加注：两支都有，但弃牌支里多了对手刚投进去的那一注。
- 全下：跟下注完全同式，只是 `B` 被筹码量锁死。
- 过牌：`B = 0` 的下界情形。

把这件事说透的检验方式很简单：任何一条你觉得"特殊情况"的式子，都应该能在 `f` 或 `B` 取某个值时还原成模板。还原不出来的，就是记号在骗你。

比较动作只需要比较它们的差，也因为基准是同一个 0：`EV(A) − EV(B)` 里所有与动作无关的项（旧投入、平分处理）都消掉了。这正是训练器能给出一手牌"你少赚了 1.62 个底池份额"的原因，也是"遗憾值"这个量存在的原因。

## 算例 / Worked examples

统一输入：翻牌圈 `8d6d2s`，底池 12，我方 `AdKd`，对手 `QsQh`。胜率用引擎穷举现算：

```
PYTHONPATH=src python -m pokergto equity "AdKd" "QsQh" --board "8d6d2s" --mode exact --json
→ "equity": 0.541414, "iterations": 990, "exact": true
```

`iterations` 是 990 而不是 1081，因为两家底牌已知，可发的转河组合被删掉了 91 个（`01-04` 讲这两者的区别）。

**例 1 — 四个动作并排。** 弃牌 `0`；过牌 `e·P = 6.4970`；跟注 `e·(12+8) − 4 = 6.8283`（面对 1/3 池下注时）；下注见例 2。

**例 2 — 三个尺度，弃牌率一律取"对手按 MDF 防守"。** `f` 因此不是我编的估计，而是 `1 − MDF` 的推论：`required_fold_frequency(12, B)`。

| 动作 | `B` | `f = B/(P+B)` | `EV` | 遗憾值 |
|---|---|---|---|---|
| 下注底池 | 12 | 0.500000 | 9.7455 | 0 |
| 下注 1/2 池 | 6 | 0.333333 | 8.6626 | 1.0828 |
| 下注 1/3 池 | 4 | 0.250000 | 8.1212 | 1.6242 |
| 过牌 | 0 | 不存在 | 6.4970 | 3.2485 |

复现：`PYTHONPATH=src python -c "from pokergto import ev, odds; e=__import__('fractions').Fraction('0.541414'); rows=ev.compare(12,[('check',0),('bet 1/3',4),('bet 1/2',6),('bet pot',12)],fold_frequencies={a:odds.required_fold_frequency(12,b) for a,b in [('bet 1/3',4),('bet 1/2',6),('bet pot',12)]}|{'check':0},equities_when_called={'check':e,'bet 1/3':e,'bet 1/2':e,'bet pot':e}); print([(r.action,round(r.ev,4)) for r in rows]); print(ev.regret(rows))"`

**例 3 — 同一批输入，只改一个假设：被跟注时的胜率随尺度下降。** 尺度越大、跟他的范围越强，于是取 `e = 0.541414 / 0.48 / 0.35`（过牌仍按 `0.541414`）：

| 动作 | `EV` | 遗憾值 |
|---|---|---|
| 下注 1/3 池 | 8.1212 | 0 |
| 下注 1/2 池 | 7.6800 | 0.4412 |
| 过牌 | 6.4970 | 1.6242 |
| 下注底池 | 6.3000 | 1.8212 |

排序整体翻转。模板没变，代码没变，变的只有一个**输入**。这就是本节最该被记住的一课：引擎不会替你判断 `e`，你把什么填进去它就替你算什么。

**例 4 — 加注的两条路（`P = 10, B₀ = 5, R = 20, f = 0.3`）**：`9.44949`（定义式）与 `9.44949`（模板代入式）；偷懒写法 `7.94949`，误差 `1.5`。

## 实战牌局 / Live hands

**牌局 1（`hand.02-06-flop-size-choice`）— 六人桌，BTN 对 CO，翻牌 `8d6d2s`，底池 12，我方 `AdKd`。**

- 胜率 `0.541414`（上面那条命令现算），因此这不是"凭感觉加注"的场合，而是比较四个候选动作。
- 在"对手按 MDF 防守 + 各尺度被跟注时胜率不变"这组前提下，底池下注最优，选 1/3 池的代价是每手 `1.6242` 个筹码的遗憾值，过牌的代价是 `3.2485`。
- 只要把"被跟注时胜率随尺度下降"这条现实输入放回模型（例 3），结论立刻变成 1/3 池最优、底池下注反而最差，遗憾值 `1.8212`。
- 所以本节能给你的不是"该下多大"，而是一句更硬的话：**你的尺度结论，强度等于你的输入强度。**第 03 章（范围优势、坚果优势）与第 04 章（尺度集合）负责给出那些输入，本节负责保证你拿到输入之后不会再算错。
- 决策落点：这一手先按"能否说清 `e` 随尺度怎么变"来判断自己有没有资格选尺度；说不清，就用最小有意义的尺度，把遗憾值控制住。

**牌局 2（`hand.02-06-raise-not-new-formula`）— 转牌圈，底池 10，对手下注 5，我方加到 20。**

- 直接按定义：`0.3 × 15 + 0.7 × (e·50 − 20)`。`e` 取本例的胜率 `0.541414` → `9.44949`。
- 按模板代入（`P₁ = 10 + 2×5 = 20`，`B₁ = 15`）：`ev_bet(20, 15, 0.3, e) − 5` → `9.44949`。两条路必须一致，不一致就是记号代错了。

## 为何成立、何时失效 / Why it works, when it breaks

**成立的前提**：一条街的单一决策、筹码线性效用、`e` 是钱进池后的真实份额、两条分支互斥且穷尽。

**会失效或被削弱的地方**：

1. **`e` 不是常数。** 不同尺度被跟注时面对的范围不同（例 3）。模板照算，但它不会提醒你别扭；只有声明假设的人才需要负责。本节把这条明写为输入而非结论。
2. **对手不止两个动作。** 有加注时，"继续"这一支要再分叉，模板要递归套用在下一条分支上——同一个式子，多一层。`02-08` 与第 06 章（过牌加注线）处理。
3. **跨街。** 模板只算一条街。翻牌下注的价值里还有"转牌能继续进攻"的选择权，那要靠博弈树把多个模板串起来（第 08 章），不是本节一个式子能表示的。
4. **效用非线性（锦标赛）。** 把 `EV` 换成 ICM 值之后模板形状不变，钱数全变（第 12 章）。
5. **平分。** `e` 的定义含半份池，所以有 `AA` 撞 `AA`、公共牌成顺子这类情形时，两支的金额都要按平分调整。
6. **遗憾值的口径。** `ev.regret(rows)` 给出的是"相对本表最优动作少赚多少"，它只在同一张候选表内可比。把两张不同前提的表的遗憾值相减，是把假设当成了数字——这是本节最需要防的误用。

## 陷阱 / Common mistakes

1. **把自己已投入的钱算进期望值。** 底池里的旧钱两个分支都拿不回来，不该出现。
   *代价*：牌局 2 里少算对手那条街的下注就差 1.5 个筹码；反方向（把自己的旧投入也当成回报）会算出更大的偏差，且不会报错，只会让你的复盘"感觉对、数字错"。
2. **给不同动作套不同公式。** 过牌一套、跟注一套、加注一套，然后在两处用不同的弃牌基准。
   *代价*：同一手牌在两个地方得到矛盾的结论，最后靠印象决定听哪一条。用 `ev.compare` 一次算完，候选动作自动共享同一个 `P` 与同一个 0 基准。
3. **把遗憾值当成"损失"来记进长期数据。** 遗憾值是相对候选集的差值，不是相对最优打法的损失，更不是 bb/100。
   *代价*：把不同候选集合的遗憾值加总，会得出"这一手输了 3 个底池"这种无法与任何表核对的数。要跨手比较，先固定候选集合与前提。
4. **只换公式不换假设。** 例 3 的排序翻转说明，讨论尺度却不说 `e` 怎么随尺度变，等于在讨论一个不存在的模型。
   *代价*：第 04 章的尺度讨论会退化成背尺度，而背来的尺度在新牌面上一律失效。

## 练习 / Drills

- 只用模板写出：弃牌、跟注 5 进 15、过牌、下注 6 进 12、加到 20（面对 5 的下注）、全下 25 进 15。然后逐项代入 `f = 0` 或 `B = 0` 检查是否能从模板还原。
- 用例 2 的输入自己跑一遍 `ev.compare`，把四个动作的遗憾值写下来；再把 `f` 全部改成 0，看哪一项变成最差。
- 用 `e = 0.30`、`P = 12`、三个尺度重复例 3，找出在哪个 `f` 上"底池下注"与"1/3 池"打平。
- 牌局 2 改参量：`R = 15` 而不是 `20`，两条路各算一次，确认还是 `9.xxxx` 一致。
- 把 `ev_shove(12, 15, e, 0.6)` 与 `ev_bet(12, 15, 0.4, e)` 都算出来，确认它们相等——这是"全下是特例"的最小证明。
