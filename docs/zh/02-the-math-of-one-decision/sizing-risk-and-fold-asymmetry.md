# 尺度的不对称：被加注的风险与弃牌带来的收益

<!-- hands: 2 -->
<!-- terms: sizing-risk, fold-asymmetry, bet-size, minimum-defense-frequency, fold-equity, offered-odds, polarized, merged, spr, overbet -->

## 本节目标 / Objectives

- 能写出"尺度变大时同时改变的两件事"：需要的弃牌率与承担的风险，并说清哪一个按线性增长、哪一个按递减速度增长。
- 能用 `02-03` 的"一条方程、两边"框架解释防守方在尺度变化时必须怎么动。
- 能算出被加注之后剩余行动的期望，并说清为什么纯空气几乎不为尺度风险付费、而中等牌替所有人付了。

## 前置知识 / Prerequisites

- `02-03` MDF 与需要的弃牌率；`02-06` 统一模板（本节在它上面加一条"被加注"分支）。
- `02-05` 弃牌赢率是 `f·P`；`02-02` 所需胜率 `B/(P+2B)`。

## 核心原理 / The principle

尺度不是"激进或保守"的表态，它是三个同时移动的量：

```
你冒的钱        B                            ← 随尺度线性增长
你必须拿到的弃牌率  f = B / (P + B)            ← 随尺度增长，但增速递减
你给对手的赔率    e_req = B / (P + 2B)        ← 随尺度增长，是他跟注的门槛
```

不对称就在这三行的**速率差**上。尺度从 1/4 池走到 2x 池，风险变成 8 倍；所需弃牌率只变成 3.33 倍；而"每单位风险需要多少弃牌率"从 `0.80` 掉到 `0.3333`，也就是掉了 57%。大注用更高的绝对风险，买到更便宜的弃牌率；小注用低得多的风险，但每一枚筹码要多讨 2.4 倍的弃牌。

这是一条 `derived` 结论：三个式子都来自 `src/pokergto/odds.py`，不依赖任何范围表。

## 推导 / Derivation

**第一步，一条方程的两边。** `02-03` 给出诈唬需要 `f = B/(P+B)`，防守方需要 `MDF = P/(P+B)`。两者相加恒等于 1：

```
B/(P+B) + P/(P+B) = 1
```

所以尺度每动一格，你手里两个数同时动、且方向相反：你下得越大，你**讨到的弃牌**越多、对手**被要求保留的范围**越小。这就是本节所有取舍的来源——你要的那部分收益和对手让出的那部分防守，是同一枚硬币。

**第二步，风险的线性与收益的凸性。** 令 `P = 1`，把 `f(B) = B/(1+B)` 对 `B` 求导：

```
df/dB = 1 / (1 + B)²
```

在 1/4 池处是 `0.64`，1/3 池处 `0.5625`，底池处 `0.25`，2x 池处 `0.1111`。所需弃牌率的**边际增量掉了 5.8 倍**，而 `B` 只是线性地涨。结论：越大的尺度，用越多的钱买到越少的新弃牌。

再用归一化的口径读一遍，因为牌桌上更好用：

```
f / B = 1 / (P + B)
```

这是"每一枚冒出去的筹码，需要换回多少弃牌率"。1/4 池 `0.80`、1/2 池 `0.6667`、底池 `0.50`、2x 池 `0.3333`。小注贵、大注便宜的正是这个比值——`02-04` 里"大尺度需要更多诈唬"是同一条事实的另一面：大尺度用便宜的价格讨弃牌，所以你付得起更松的构成。

**第三步，被加注之后剩余的行动。** `02-06` 的模板只有两支；加上"对手加注、你弃牌"就有三支。设你下注 `B`，对手加到 `R` 的概率为 `r`，你选择弃牌，则

```
EV(bet) = f·P + (1 − f)·[ (1 − r)·( e·(P + 2B) − B ) + r·( −B ) ]
```

关键观察在最右边那项：**被加注后弃牌，损失是 `B`——和被跟注然后输光的损失一样多。**于是对纯空气（`e = 0`），加注这件事根本不改变期望值：`EV(bluff) = f·P − (1 − f)·B`，与 `r` 无关（核对：`ev_pure_bluff(10, 5, 1/3) = 0.0`）。

这就是不对称的真正落点。**尺度风险不是由空气付的，是由中等牌付的。**空气被加注就弃，`B` 本来就是打算丢的；而一手有胜率的牌，本来可以在被跟注时赢 `P + B`，现在因为尺度太大被人加到 `R`，要么弃牌把 `B` 丢掉，要么按更高的价格跟下去。要继续就得付更高的价格，门槛写成闭式很短：配平后的池是 `P + 2B`，你再补 `R − B`，两家补齐时最终池子为 `P + 2R`，所以

```
e_req = (R − B) / (P + 2R)
```

`P = 10, B = 5, R = 20` → `15/50 = 30%`。用引擎更省事——把加注看成"先跟 `B`、再把多出来的 `R − B` 投进已经配平的池 `P + 2B`"（`02-06`）：

```
equity_needed_to_call(P + 2B, R − B)
底池 10、你下 5：加到 12 → 20.59%；加到 15 → 25.00%；加到 20 → 30.00%；加到 30 → 35.71%
```

对手只是把加注**变大**，你就必须有更强的牌才能继续。这条变化不发生在空气身上（它总会弃），只发生在你的中间段身上。

## 直觉 / Intuition

把两个极端想清楚，中间的取舍就不神秘了。

- **小注像撒网。** 你只丢 1/4 池，被加注了也不心疼，被跟注了也没输多少；代价是这条网要收很多弃牌才回本（`f/B = 0.80`），而 1/4 池要求的弃牌率只有 20%——你讨不到多少，因为对手跟小注太舒服了。小注的真正限制不是风险，是"骗不到人"。
- **大注像买断。** 2x 池只需要 33.33% 的防守就能把你送到门槛（`f = 66.67%`），弃牌便宜；但你一次要押 2 个池，而且你的中等牌会被加注逼到"要么白丢 2 个池，要么付 35.71% 的价去跟"。

所以"该用哪个尺度"从来不是单一答案：同一手牌，空气用得上大注，中等牌用不上，坚果用得最好（他加注你可以再加注）。第 03 章的范围优势与坚果优势、第 04 章的尺度集合，负责给出"谁在这张牌面上能用大注"；本节只负责一件事：**告诉你不同强度为同一个尺度付的价格不一样。**

| 1/3 池 | 0.3333 | 25.00% | 0.7500 | 0.5625 |

**例 2 — 中等牌被加注定价（`P = 10, B₀ = 5`）。** 对手加到 `R` 时你需要继续的胜率：`R = 12 → 20.59%`，`15 → 25.00%`，`20 → 30.00%`，`30 → 35.71%`。复现：`PYTHONPATH=src python -c "from pokergto.odds import equity_needed_to_call as q; print([(R, round(q(20, R-5), 4)) for R in (12,15,20,30)])"`（`P+2B₀ = 20`）。

**例 3 — 加注风险吃掉多少大注红利。** 底池 10、`f = 0.3`，被跟注时胜率 `e = 0.62`（领先的牌），`r` 分别为 0 与 0.15：

| `B` | `r = 0` | `r = 0.15` |
|---|---|---|
| 4（1/3 池） | 8.0120 | 6.8402 |
| 5（1/2 池） | 8.1800 | 6.8780 |
| 10（底池） | 9.0200 | 7.0670 |

底池对 1/3 池的优势从 `1.0080` 缩到 `0.2268`，被抹掉 77.5%。
复现：`PYTHONPATH=src python -c "P=10;f=0.3;EV=lambda B,e,r: f*P+(1-f)*((1-r)*(e*(P+2*B)-B)+r*(-B)); print([(B, round(EV(B,0.62,0),4), round(EV(B,0.62,0.15),4)) for B in (4,5,10)])"`

**例 4 — 同一条命令换成 `e = 0.45`（中等偏弱的牌）**：`B = 4 → 5.8700 / 5.0195`，`B = 5 → 5.8000 / 4.8550`，`B = 10 → 5.4500 / 4.0325`。没有加注威胁时小注已经更好；有加注威胁时小注更好的幅度从 `0.42` 扩大到 `0.99`。**同一张表、同一个 `r`，只把 `e` 从 0.62 换成 0.45，最优尺度就从底池跑到 1/3 池**（`r` 是对手模型输入，见来源表）。

**例 5 — 防守方一侧的双门槛。** 尺度从 1/3 池换到 2x 池，你要动的不只是一个数：`MDF` 从 75% 掉到 33.33%（配额），而 `equity_needed_to_call` 从 20% 涨到 40%（手上的牌）。用 `poker odds --pot 1` 一列列读，别只记前一个。

## 实战牌局 / Live hands

**牌局 1（`hand.02-08-turn-size-and-raise-risk`）— 转牌圈，牌面 `AcKd8s5h`，底池 10，我方 `KsQh`（顶对好踢脚，被跟注时 `e = 0.62`），对手有 15% 的过牌加注率。**

- 三个尺度的期望值就是例 3 的三行：底池下注最好（`7.0670`），1/3 池 `6.8402`，代价 `0.2268`。
- 注意红利有多薄：没有加注威胁时底池比 1/3 池多赚 `1.008`，有 15% 的加注威胁后只剩 `0.2268`。**大注的红利几乎被一条加注线拿走了**，所以决定尺度的往往不是"他想不想跟"，而是"他加了你怎么办"。
- 如果 `e` 从 `0.62` 掉到 `0.45`（例 4），排序直接反过来：`5.0195` 对 `4.0325`，底池下注变成最差。同一张牌面、同一个加注率，只因为牌力档位不同，最优尺度换了整档。
- 落点：先问"我这手在被加注之后还有没有第二条路（跟注、再加注）"。有 → 大注付得起；没有 → 小注或过牌，别把 `B` 白送。

**牌局 2（`hand.02-08-river-overbet-air`）— 河牌圈，底池 20，我方纯空气，考虑 2x 池超池下注 40。**

- 需要的弃牌率 `B/(P+B) = 40/60 = 66.67%`，MDF 只有 `33.33%`（`poker mdf --pot 20 --bet 40`）。弃牌便宜是超池下注唯一的优点。
- 加注风险对空气定价为零：`EV(bluff) = f·P − (1 − f)·B` 里没有 `r`。对手加注你也弃，损失都是 `B = 40`；这一点与牌局 1 的中等牌形成节内最关键的对照。
- 但空气为**弃牌率估计**付全额：`f` 从 70% 掉到 50%，期望值从 `+2.0` 变 `−10.0`（`02-05` 例 5）。所以超池诈唬的正确检查顺序是：先问 `f` 有没有数据来源，再问范围里有没有 40% 的空气配额（`02-04`），最后才问"我怕不怕被加注"——那一条对空气不算问题。
- 这也解释了为什么大尺度在实战里跟着极化形状出现：顶端（坚果被加注可以再加注）与底端（空气被加注就弃）都付得起，中间段付不起。**形状结论属于第 04 章，本节只给机制。**

## 为何成立、何时失效 / Why it works, when it breaks

**成立前提**：一条街内的期望值、被加注后你确实弃牌、对手加注率 `r` 不随你的尺度改变、`e` 在被跟注时成立、筹码线性效用。

**失效处**：

1. **`r` 与尺度相关。** 现实中越大的尺度触发越多加注（对手只有更强才敢加），`r = r(B)` 会让例 3 的侵蚀更陡。引擎可以给 `r(B)` 任意形状的输入，但不会替你估计它；这是第 04 章与对手模型的事。
2. **被加注后你不弃牌。** 只要你有跟注或再加注的第二条路，`r·(−B)` 那一项就要换成期望值更小的分支，本节关于"空气不受加注风险影响"的结论就只对**真的会弃牌**的空气成立。
3. **多人底池。** 两家人都可能加注，`f` 要按合并弃牌率算（`02-05` 例 4），加注分支还要乘两家都不加注的概率。`07-02` 之后处理。
4. **有后续街。** 本节的"损失 `B`"在一条街的账上算完；转牌的下注还带着河牌的选择权（`06-05` 二次开火），把它省掉会让小注显得比实际更好。
5. **深筹码。** `B` 的上限由后手决定。`table.03-07.spr-commitment` 显示全下门槛随 `SPR` 收敛到 50%，所以"尺度风险"在 `SPR < 1` 时几乎不是问题、在 `SPR > 4` 时是主要问题（`03-08` 套池）。
6. **效用非线性。** 锦标赛泡沫期，`B` 的代价远大于线性（第 12 章）。

**明确不回答的问题**：该用哪个尺度。这由范围优势与坚果优势决定（第 03 章），再由尺度集合与频率法决定（第 04 章）。本节只处理风险/需求的取舍，与牌面质地无关；把"这张面适合大注"当成结论写进来，就是超出来源的断言。

## 陷阱 / Common mistakes

1. **把"需要的弃牌率"读成"越大的越好骗"。** 大注确实讨到更多弃牌（`f` 从 20% 涨到 66.67%），但它是用 8 倍的风险换来的；用 `f/B` 那列才是同口径比较：`0.80 → 0.3333`。
   *代价*：以为大注"最有效率"而在河牌反复超池，实际上你在为一个递减的边际付线性增长的钱。核对：`poker odds --pot 1` 的第二列与第四列一起读。
2. **以为大尺度范围要紧。** 与 `02-04` 同一条错误的另一面：2x 池要求 40% 的诈唬份额，是阶梯上最高的。
   *代价*：只带价值去下超池，对手弃掉全部中等牌，你的价值段从此只赢 `P`。配比在 `table.02-04.bluff-value-ratio`（`02-04` 已推导），尺度选它却付不起配额，就是本节例 3 那种被抹掉的红利。
3. **给所有牌同一个尺度答案。** 例 3 与例 4 唯一差的是 `e`（0.62 对 0.45），最优尺度就从底池变成 1/3 池。
   *代价*：把"这手牌这个尺度"当成通用规则搬走，等于把 0.987 个筹码/手的差价值当零头放弃。
4. **只调防守频率、不调手上的门槛。** 尺度从 1/3 池变到底池，`MDF` 从 75% 掉到 50%，同时所需胜率从 20% 涨到 33.33%。
   *代价*：用"范围要弃更多"来决定具体弃哪手，结果弃掉的是抓诈唬牌、留住的是听牌——配额达标而单手上全是错的。两个数一起用 `poker odds --pot 20` 与 `poker mdf --pot 20 --bet 20` 查。
