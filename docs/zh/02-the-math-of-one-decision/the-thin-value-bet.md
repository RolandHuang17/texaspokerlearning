# 薄价值下注：只赢一点点也值得打的判定条件

<!-- hands: 2 -->
<!-- terms: thin-value, value-bet, value-range, bluff-catcher, required-equity, indifference, fold-equity, pot, bet, combos -->

## 本节目标 / Objectives

- 能用"被跟注时你领先的概率"与"过牌到摊牌的胜率"两个量，写出薄价值的判定条件，而不是用"我这牌不错"当理由。
- 能推出精确的保本点：在给定的弃牌率与被跟注范围下，你必须领先跟注范围多少才算值得下注。
- 能说清引擎在这里能算什么、不能算什么：它算胜率与门槛，而"对手会不会以更差的牌跟注"是对手模型的输入。

## 前置知识 / Prerequisites

- `02-04` 诈唬与价值比（薄价值牌正属于"价值段"里最靠下那一块）。
- `02-06` 统一模板与 `EV(check) = e·P`；`02-05` 弃牌赢率是 `f·P`。

## 核心原理 / The principle

先把三个类别用算术分开，别用形容词分开。记：

```
q  = 被跟注时你领先的概率（对手跟注范围里，你能压住的那部分组合数占比）
e₀ = 你过牌、双方都过牌到摊牌时你领先的概率
```

| 类别 | 判定条件 | 含义 |
|---|---|---|
| 厚价值 | `q·(P + 2B) − B ≥ e₀·P` | 对手百分百跟注也值得下注，弃牌支是额外收入 |
| 薄价值 | `q > 1/2` 但 `q·(P + 2B) − B < e₀·P` | 你确实领先跟注范围，但必须靠弃牌支补差价 |
| 诈唬 | `q ≤ 1/2` | 跟你牌的牌里，比你好的占一半以上，这不是价值下注 |

`02-04` 里"价值下注"的定义是"指望对手以更差牌跟注"，所以 `q > 1/2` 是价值的下限；而"薄"来自第二行的不等式：**赢的时候只赢 `P + B`，输的时候输掉 `B`，而这条路只有靠 `f·P` 才走得通。**

## 推导 / Derivation

下注与过牌两条路的期望值，直接来自 `02-06` 的模板：

```
EV(bet)   = f·P + (1 − f)·( q·(P + 2B) − B )
EV(check) = e₀·P
```

被跟注那一支写成 `q·(P + 2B) − B` 是因为：领先时你净得 `P + B`，落后时你净赔 `B`，两者按 `q` 与 `1 − q` 加权正好等于它（展开核对：`q(P+B) − (1−q)B = qP + 2qB − B`）。

下注不比过牌差，条件就是：

```
f·P + (1 − f)·( q·(P + 2B) − B ) ≥ e₀·P
```

这是关于 `q` 的一次不等式，解出来就是本节的保本点：

```
q* = ( (e₀ − f)·P + (1 − f)·B ) / ( (1 − f)·(P + 2B) )
```

`q ≥ q*` 时下注，`q < q*` 时过牌。分母里那个 `P + 2B` 就是 `02-02` 的"最终池子"：这**不是新公式**，是把抓诈唬牌那一侧的无差别条件反过来解——他把 `B/(P+2B)` 当作需要的胜率，你把同一个 `P + 2B` 当作你必须压过的门槛。

**两个能一眼记住的极限。**

一、`f = 0`（对手从不弃牌），且暂时令 `e₀ = q`（最粗的近似：跟注范围与全范围一样弱）：

```
q* = [(1−f)B − fP] / [2B − f(P+2B)] = B / 2B = 1/2
```

没有弃牌赢率时，下注必须实打实压过跟注范围，正是"价值"这个词的原味。

二、`f = B/(P+B)`，也就是对手按 `02-03` 的 MDF 防守（`q* = 0`）：

```
分子 = (1 − f)B − fP = [P/(P+B)]·B − [B/(P+B)]·P = 0
```

在这个模型里，对手只要按地板线弃牌，任何下注都不差于过牌。**这条既是本节最强的结论，也是本节最大的警告**：它说明"该不该下注"这件事，MDF 一条线管不了——它管的是对手的动作，不是你的范围结构。真实情况是 `e₀ > q`（跟注你的人比全范围强），差价 `e₀ − q` 就是薄价值必须用弃牌赢率支付的保费。

把保本点写成"需要多少弃牌率"更实用（对 `f` 解一次）：

```
f* = ( e₀·P − A ) / ( P − A ),   其中 A = q·(P + 2B) − B
```

## 直觉 / Intuition

薄价值是一次**用赢面换频率**的买卖：你不靠"他一定跟"赚钱，你靠"他跟的时候我赢的比他跟别的牌多一点，而他不跟的时候我白拿底池"。所以判断薄价值永远要问两件事：

1. **跟注范围里我压得住多少？**（`q`）这决定了它到底算价值还是算诈唬。
2. **我过牌的话能白赢多少？**（`e₀`）过牌不是零，它往往比你想的更值钱——差值 `e₀ − q` 越大，你这注就越薄，越依赖弃牌支。

第二问最容易被跳过，也正是薄价值翻车的地方：中等牌过牌常常能赢那些"不会跟注的更差牌"，把它们拿来下注反而会被更强的牌跟。用一句话概括：**薄价值下注是把"稳赢的小池"换成"有时候多赢一点、有时候全输"的组合，只有当对方弃牌足够频繁，换过来的差价才为正。**

## 算例 / Worked examples

**例 1 — 保本点随弃牌率塌陷（`P = 10, B = 5`，取 `e₀ = q` 这一简化口径）。**

| 对手弃牌率 `f` | 你需要领先跟注范围的比例 `q*` |
|---|---|
| 0% | 50.00% |
| 10% | 43.75% |
| 20% | 33.33% |
| 30% | 12.50% |
| 33.33% = `B/(P+B)` | 0% |

每一行都可以用两条期望值核对，例如 `PYTHONPATH=src python -c "from pokergto import ev; print(ev.ev_bet(10,5,0.2,1/3), ev.ev_check(10,1/3))"` → 两个都是 `3.3333`。这张表的意思很直白：**弃牌率每往上走一点，你的牌可以更差一点。**

**例 2 — 判定某一手属于哪一类。** 底池 20、下注 10（1/2 池），被跟注时领先的比例 `q = 34/59 = 57.63%`，过牌胜率 `e₀ = 0.72`（两个都是输入，见下面的来源说明）。

- `q > 1/2`：是价值，不是诈唬。
- 取 `f = 0`：`A = 0.576271 × 40 − 10 = 13.0508`，而 `EV(check) = e₀·P = 14.4`。`13.0508 < 14.4` → **不是厚价值，是薄价值**：没有弃牌赢率时这注不该打。
- 需要的弃牌率 `f* = (14.4 − 13.0508)/(20 − 13.0508) = 0.194146`，即 19.41%。
- 用门槛口径再核一遍：`f = 1/3`（1/2 池的 MDF 推论）时 `q* = ((0.72 − 1/3)×20 + (2/3)×10)/((2/3)×40) = 0.54`，而 `q = 0.5763 > 0.54` → 下注。

**例 3 — 同一个尺度，`e₀` 差一点结论就反。** 保持 `q = 0.5763`、`P = 20, B = 10, f = 1/3`，把 `e₀` 从 `0.72` 抬到 `0.78`：`q*` 从 `0.54` 变成 `0.585`，而 `q = 0.5763` 落在下面 → 同样的对手频率、同一手牌，只改一个 `e₀` 估计，动作就从下注翻成过牌。翻转点可以精确解出来：`e₀ ≈ 0.7684`（此时 `q* = q`，`f* = 33.34%`，恰好等于 1/2 池的门槛弃牌率）。所以本节的敏感性不在尺度上，**在"过牌值多少"这个估计上**：`0.72` 与 `0.78` 的差只有 6 个百分点，却决定了整条线。

**例 4 — 换尺度就换类别。** `P = 20` 时下到底池（`B = 20`），跟注范围变强：`q = 12/34 = 35.29%`、`e₀ = 0.55`。

- `q ≤ 1/2` → 按定义它已经不是价值下注，而是诈唬。
- `A = 0.352941 × 60 − 20 = 1.1765`；`f* = (0.55×20 − 1.1765)/(20 − 1.1765) = 0.521875`，需要 52.19% 的弃牌率。
- 而底池下注只被 MDF 保证 50% 的弃牌率。差 2.19 个百分点，且方向是"要得比理论能给的多" → 过牌。

**例 5 — 与 `02-04` 的配比对齐。** 1/2 池的诈唬份额是 25%，配比 3:1。薄价值牌属于那 75% 的价值段里最靠下的一格：它进不了"谁都压得住"的厚段，但按 `q > 1/2` 也不算空气。配比管的是范围里两段的相对数量，`q*` 管的是分界线画在哪一格。两个条件都得满足，一个动作才算既合法又赚钱。

## 为何成立、何时失效 / Why it works, when it breaks

**成立的前提**：一条街、单一决策点、被跟注时只有"领先/落后"两种结果（无平分）、`q` 与 `e₀` 是给定对手模型下的真实值、对手不会因为你下注而改变他后续街的行为。

**失效或被削弱的地方**：

1. **`e₀` 与 `q` 都是输入，不是结论。** 引擎能算的只有：由具体手牌/范围与牌面枚举胜率（`poker equity`），以及各种门槛（`poker odds`）。"对手会不会以更差的牌跟注这 1/2 池下注"是一句关于对手策略的断言。本节的 `34/59`、`e₀ = 0.72` 都是**作者设定的模型输入**，属 **UNVERIFIED / 未核验**；把它们换成可核验数字的路径写在下面来源表里。
2. **有平分。** 河牌出现 `AA` 撞 `AA`、公共牌成顺子时，`q` 与 `1 − q` 之间还有一档半赢，`q*` 会小幅上移。本节的封闭解不含这一档。
3. **多人底池。** `f` 变成"所有人都弃"，且每个跟注者的范围不同，`q` 要按各家的组合数重新加权；`07-02` 之后处理。
4. **不是河牌。** 转牌圈的薄价值下注还带"保护"与"下一条街的进攻权"两项收益（`04-06`、`06-05`），把它们省掉会让 `EV(bet)` 被低估，但方向是让你更保守，不是更冒险。
5. **对手按 MDF 防守这一极限。** 例 1 的最后一行（`q* = 0`）说明：在这个单街模型里，只要对手弃够门槛率，任何牌下注都不差于过牌。真实牌局不这么打，因为过牌范围也要有顶端——你把中等牌全下注，过牌线就空了，对手可以随便攻击。这条修正属于第 04 章的**合并 / 极化**范围形状与过牌范围构造，不在本节证明范围内。
6. **锦标赛。** 筹码的效用非线性时，`P` 要换成 ICM 值，薄价值常变成过牌（第 12 章）。

## 陷阱 / Common mistakes

1. **用"我有好牌"当薄价值的理由。** 判据是 `q > 1/2`（是不是价值）加一个不等式（要不要弃牌赢率补差价），不是牌力形容词。
   *代价*：例 4 那一类动作会被误记为"薄价值打得没问题"，而它其实需要 52.19% 的弃牌率、理论上只有 50% 可以指望。缺口 2.19 个百分点换算成期望值是每手 `−0.412` 个筹码（`EV(bet) = 10.5882` 对 `EV(check) = 11.0000`）。一次不多，但河牌上这类决定每回合都在做，而它整段是负的。
2. **用摊牌胜率代替 `q`。** `q` 是**被跟注条件下**的领先比例；整手牌的胜率（包括对手弃牌的那部分）比它高，也毫无用处。
   *代价*：`q` 被高估 → `q*` 门槛轻松"通过"，你把诈唬当成价值下注打。用 `poker equity` 时务必把范围设成"他会跟注的那些牌"，不是他的全部范围。
3. **忘了 `e₀`。** 把过牌的期望当成 0 或当成 `q·P`，是最省事的错。
   *代价*：例 3 显示 `e₀` 从 0.72 到 0.75 就能让同一个动作从下注翻成过牌。把过牌当成 0 更会得出"所有能压住跟注范围的牌都该下注"，那是范围过度下注，会把过牌线掏空。
4. **把"薄价值"和"抓诈唬牌"混写。** 术语表里 `bluff-catcher`（抓诈唬牌）是只能赢诈唬、赢不了价值的牌，正好在 `q ≤ 1/2` 那一侧；薄价值牌在另一侧。
   *代价*：两个词的判定条件相反，混用之后你既不能判断该下注，也不能判断该跟注。
