# 弃牌赢率：一次下注里唯一由对手决定的收益

<!-- hands: 2 -->
<!-- terms: fold-equity, fold-frequency, expected-value, ev-decomposition, bluff, minimum-defense-frequency, semi-bluff, pot, bet, range -->

## 本节目标 / Objectives

- 能把一次下注的期望值拆成"对手弃牌"与"对手继续"两支，并写出弃牌赢率就是第一支 `f·P`。
- 能说清弃牌赢率的上限在哪里，以及为什么在对手按最低防守频率（MDF）防守时，纯诈唬的弃牌赢率被风险刚好吃光。
- 能把"我这手牌有不少弃牌赢率"翻译成一句关于**对手**的可检验陈述，并知道用什么数据检验它。

## 前置知识 / Prerequisites

- `02-01` 保本百分比；`02-04` 诈唬与价值比（本节沿用它的无差别思路，但换成下注方视角）。
- `02-03` MDF 与需要的弃牌率 `B/(P+B)`。

## 核心原理 / The principle

弃牌赢率不是一种独立的收益，它是下注期望值里的第一项：

```
EV(bet) = f·P + (1 − f)·(e·(P + 2B) − B)
          ↑        ↑
        弃牌赢率   被跟注那一支
```

`f` 是**所有**对手都弃牌的概率，`P` 是此刻池里能被收走的钱，`e` 是被跟注后的胜率。术语表把弃牌赢率定义为"对手弃牌概率 × 当下可收的底池"，也就是 `f·P`；它和"弃牌频率"只差一个字，但一个是钱、一个是频率，写错就变成两个不同的量。

## 推导 / Derivation

一次下注只有两种结局，所以期望值必然只有两项。

**第一支**：对手弃牌（概率 `f`）。你冒的 `B` 一分没花出去就被退回，池里的 `P` 归你：`+P`。这一支的值是 `f·P`。

**第二支**：对手继续（概率 `1 − f`）。钱进底池，最终池子 `P + 2B`，你占的份额期望是 `e·(P + 2B)`，你在这条街投进去的是 `B`：净 `e·(P + 2B) − B`。

两支相加就是模板。纯诈唬是 `e = 0` 的特例：

```
EV(bluff) = f·P − (1 − f)·B
```

令它为 0，解出的正是 `02-03` 的那个门槛：

```
f·P = (1 − f)·B  →  f = B / (P + B)
```

于是得到本节最重要的一句话：**对手只要按 MDF 防守，你的纯诈唬期望值就正好是 0。**弃牌赢率没有给你任何多余的东西，它精确地被"被跟注时输掉 `B`"这条支抵消。诈唬能赚钱，只有在对手防守不足的时候——也就是只有在他偏离 `02-03` 那条地板线的时候。

再问一句：弃牌赢率有多大的天花板？因为 `f ≤ 1`，

```
f·P ≤ P
```

一手空气的下注，一辈子最多赚走它当下看到的底池。而 `f = 1` 需要对手从不防守，那是 `MDF = 0`，与 `P/(P+B) > 0` 矛盾。所以弃牌赢率不仅有个上限，而且这个上限在均衡里永远取不到。

最后是敏感度：`EV(bluff) = f·(P + B) − B`，对 `f` 的斜率是 `P + B`。底池 10、下注 5 时，每多一个百分点的弃牌率值 `0.15` 个筹码。这个数字比"感觉对手很怕我"有用。

## 直觉 / Intuition

弃牌赢率是**对手的策略在你账上留下的余额**，它不是你的牌的属性。你能控制的只有两件事：你摆出的范围形象，和你索取的价格。剩下那部分——他跟不跟——是他的决定。

三个左右 `f` 的东西，按重要性排：

1. **你这条行动线代表什么范围。** 同一手空气，在"翻牌下注、转牌再开火"的线上骗到的弃牌，跟在"过牌后再下一注"的线上完全不同。这是第 03、06 章的内容。
2. **尺度。** 尺度越大，你需要越多弃牌才回本（`B/(P+B)` 随 `B` 单调上升），但每一点弃牌也越发值钱，因为斜率是 `P + B`。
3. **他自己是不是守地板线的人。** 一个长期弃牌率高于 `B/(P+B)` 的对手会让诈唬从 0 期望变成正期望；反过来，一个守得住的对手会让你的诈唬变成纯付学费。

心智模型：把 `f·P` 想成"你能收的租金"，把 `(1 − f)·B` 想成"你要付的保费"。诈唬能不能打，不看租金多少，看租金减保费。

## 算例 / Worked examples

**例 1 — 底池 10、下注 5（1/2 池）的空气下注。**

| 对手弃牌率 `f` | 弃牌赢率 `f·P` | `EV(bluff)` |
|---|---|---|
| 10% | 1.0 | −3.5 |
| 33.33%（门槛） | 3.33 | 0.0 |
| 40% | 4.0 | +1.0 |
| 50% | 5.0 | +2.5 |

复现：`PYTHONPATH=src python -c "from pokergto.ev import ev_pure_bluff as e; print(e(10,5,0.4))"`。门槛值 `B/(P+B) = 5/15 = 33.33%`，与 `poker odds --pot 10` 那一行的弃牌率列一致。

**例 2 — 天花板。** 同样 `P = 10, B = 5`，令 `f = 1`：`EV = 10`，等于整个底池。这就是空气下注的理论极限，而它要求对手从不防守。现实中 `MDF = 66.67%` 就把 `f` 压在 33.33%，所以例 1 里 `+2.5` 那一行已经是"对手明显漏防守"的情形。

**例 3 — 半诈唬：弃牌赢率把负期望买成正期望。** 转牌圈底池 12，你全下 15，手里是 9 张补牌的听牌。只在成牌时赢，成牌概率取 `table.01-03.draw-probability-exact-vs-rule` 的穷举值 `19.1489%`（下一张牌）。
- 对手 100% 跟：`EV = −6.9575`（`ev_shove(12,15,0.191489, 1)`）。
- 对手 60% 跟（`f = 0.4`）：`EV = +0.6255`。
- 其中弃牌那支贡献 `0.4 × 12 = 4.8`。也就是说这记全下的全部利润，是对手"不跟"那 40% 买来的；听牌本身在摊牌上是亏的。

**例 4 — 多人底池：`f` 是"所有人都弃"。** 底池 12、下注 12，两名对手。需要的合并弃牌率仍是 `B/(P+B) = 50%`，而这要求**每人**弃 `70.71%`（因为每人只需防守 `29.2893%`）。
复现：`poker mdf --pot 12 --bet 12 --opponents 2 --json` 给出 `per_player_defense = 0.292893`、`joint_defense = 0.5`。每人刚好弃 `70.71%` 时，合并弃牌率恰好 50%，诈唬期望值恰好 `0.0`——门槛与供给在这一刻是同一件事。
错法是把"每人 70.71%"直接当 `f` 填进公式：`ev_pure_bluff(12, 12, 0.7071)` 给出 `+4.8`，于是一个本来不赚不亏的诈唬在你账上变成了每手赚 4.8 个筹码。用 `poker mdf --pot 12 --bet 12 --opponents 2` 读 `joint_defense` 就不会犯这个错。`07-01` 讲这件事。

**例 5 — 大尺度的弃牌需求。** `P = 20, B = 40`（2x 池）：门槛 `40/60 = 66.67%`。对手弃 70% 时 `EV = +2.0`；弃 50% 时 `EV = −10.0`。同一个动作、同一手牌，只是弃牌率从 70% 掉到 50%，每手差 12 个筹码。

## 实战牌局 / Live hands

**牌局 1（`hand.02-05-semi-bluff-shove`）— 单挑，转牌圈牌面 `AdKc8s5d`，底池 12，我方 `QdJs` 类听牌，后手 15，全下。**

- 只在成牌时赢：9 张补牌，河牌命中概率 `19.1489%`（穷举值，见上面的表）。若对手必跟，`EV = −6.9575`：这是一记纯粹的送钱。
- 对手跟注 60% 时 `EV = +0.6255`；正的部分全部来自弃牌那支 `f·P = 4.8`。
- 于是这记全下的成立条件是一句关于对手的陈述："他在这条线上至少弃 40%"。把它和门槛对齐：`B/(P+B)` 在这种全下情形是 `15/27 = 55.56%`——注意门槛比 40% 还高，说明对**纯空气**来说这记全下是不够的；`QdJs` 敢打，是因为它不是空气，它有成牌那 19.15% 的胜率垫在后面。
- 检验方式：记录这名对手在面对转牌全下时的实际弃牌率，与 `40%` 比。`0/40/100` 的差值就是本节例 5 那种可以直接换算成筹码的量。

**牌局 2（`hand.02-05-assumed-fold`）— 河牌圈，底池 20，对手过牌，你下注 40（2x 池）诈唬。**

- 你需要 `40/60 = 66.67%` 的弃牌率。你脑中的估算是"他面对超池下注一般会弃 70%"，按这个估算 `EV = +2.0`，动作看起来合理。
- 真实情况：这名对手守得住地板线，弃牌率正好 `50%`。`EV = −10.0`。
- 漏点不在尺度选择（那是第 04 章的事），在于你把一个**没有数据来源的估计**放进了公式。`+2.0` 与 `−10.0` 之间那 12 个筹码，全部来自"我以为他有弃牌赢率"。
- 修法只有一条：写下 `f` 之前先写下它的来源。可能是你自己的手牌记录（几百手同一节点的弃牌次数），可能是 `13-02` 的 HUD 口径，也可能只能写成"无数据，按 MDF 假设 `f = 1 − MDF`"。第三种写法会让你的诈唬期望回到 0，也就是告诉你：没有证据时，纯诈唬不该打。

## 为何成立、何时失效 / Why it works, when it breaks

**成立的前提**：`f` 是"所有对手同时弃牌"的概率；`P` 是他们弃牌时你能收到的全部钱；两个支的权重加起来是 1；筹码的效用是线性的。

**不再成立的几种情形**：

1. **多人底池。** 各防守者不弃牌的概率相乘，弃牌赢率塌得比想象中快（例 4）。公式在 `pokergto.odds.defense_frequency_multiway`，独立防守假设写在生成物的 `provenance.assumptions` 里，因为牌面移除让"独立"只是近似。
2. **锦标赛的钱圈边缘。** 筹码不再是线性效用，弃牌赢率买到的是"多活一手"，其价值高于 `f·P`；同一处的风险也被 ICM 重新定价。方向不是单一的，第 12 章用 `icm` 逐手算。
3. **对手加注。** 本节把"继续"这一支全算成被跟注。若防守方会加注，你的一支变成三种结果（弃牌、跟注、加注），`f` 的含义也要跟着改——加注时你输掉的是 `B` 而不是 `e·(P+2B) − B`。`02-08` 展开。
4. **你在用弃牌赢率替代范围判断。** 一手牌能不能下注，先取决于它在下注范围里的配额（`02-04`）；弃牌赢率只决定这个动作赚不赚钱，不决定它该不该出现在范围里。这两个问题混用会产生"有弃牌赢率所以随便诈唬"的漏点。
5. **`f` 没有来源。** 本节所有例子的 `f` 都是声明的输入或 `1 − MDF` 推出的门槛。真实对手的实际弃牌频率，本仓库尚未提供数据支撑，属于 **UNVERIFIED / 未核验**。验证路径：`data/src/spots/*.yaml` 建决策点样本 + 训练器回收作答分布 + `13-02` 的统计口径。

## 陷阱 / Common mistakes

1. **把弃牌赢率当成自己牌的属性。** "我有两张高牌，所以有弃牌赢率"——弃牌赢率是对方的频率乘上池里的钱，跟你的牌只有间接关系（牌决定你能骗到谁）。
   *代价*：在守地板线的对手面前，`EV = 0`，你所有的诈唬成本都变成学费。检验：`poker mdf --pot 10 --bet 5` 拿到 66.67%，你的目标弃牌率 33.33% 就是从这条线推出来的。
2. **把两支重复计价。** 常见写法是 `EV = f·P + e·(P + 2B)`，忘了第二支要乘 `1 − f`，也忘了减掉 `B`。
   *代价*：例 3 里正确值 `+0.6255` 会被算成 `0.4×12 + 0.191489×42 = 12.84`，高估 12 倍。用 `pokergto.ev.ev_bet` 跑一遍就能看出模板少写了两个括号。
3. **把"每人弃牌率"当成"整体弃牌率"。** 两名对手各弃 70.71%，合并弃牌率是 50%，不是 70.71%。
   *代价*：例 4 里那个本来期望值为 0 的诈唬会被记成每手 `+4.8` 个筹码，于是你会持续在多人底池里下"账面上赚钱"的注。每个人的弃牌率看起来都够高，所以日志里看不出问题——错的是把它们乘起来这一步。用 `poker mdf --pot 12 --bet 12 --opponents 2` 直接读 `joint_defense`。

## 练习 / Drills

- 默写：`1/4, 1/3, 1/2, 2/3, 1, 2` 倍池底各自需要的弃牌率，用 `poker odds --pot 10` 检查。
- 一手 9 补牌听牌，底池 12、全下 15。对手跟注率分别 100%、70%、50%，用 `ev_shove` 算三个期望值，找出让它转负的临界跟注率。
- 反推：你在 20 的底池上下 10，若对手只防守 55%，你的空气下注每手赚多少？（`EV = f·P − (1−f)B`，`f = 45%`。）
- 三人底池，`P = 24, B = 12`：每人需要弃多少才刚好让你的诈唬回本？（提示：`1 − 每人防守`，用 `poker mdf --pot 24 --bet 12 --opponents 3`。）
- 写一份"弃牌赢率来源表"：给你最常打的三个节点，各写下 `f` 的估计值和数据条数；没有数据的写 `无来源，按 1 − MDF`。
