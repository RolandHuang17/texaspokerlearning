# 保本百分比：一次跟注承担的风险对应多少回报

<!-- hands: 2 -->
<!-- terms: expected-value, break-even-percentage, pot-odds, required-equity, pot, bet, call, fold, raise, bluff, shove, overfold -->

## 本节目标 / Objectives

- 能用一个式子 `risk/(risk + reward)` 写出任何一次赌博的保本胜率，并且说清 `risk` 与 `reward` 各自在**决策的那一刻**量的是哪一笔钱。
- 能把它分别用在跟注、诈唬、3-bet 诈唬、全下四种动作上，并说出每一种里"成功"指的是什么事件。
- 能当场指出"回报就是你赢下的底池"这句话最容易量错的两种方向，各偏出多少个百分点，以及它们分别把人推向过度弃牌还是过度跟注。

## 前置知识 / Prerequisites

- `00-02` GTO 与期望值（EV）：为什么"长期平均"是唯一能被验证的单位。
- `01-07` 13×13 网格：组合数口径与类别口径的区别——本节所有"百分比"都必须先站在这个单位上。

## 核心原理 / The principle

一次只有两种结局的赌博：赢的时候净得 `reward`，输的时候净付 `risk`。要让它不亏，成功概率至少要

```
break-even = risk / (risk + reward)
```

引擎里就是 `pokergto.odds.break_even_percentage(risk, reward)`，默认走 `Fraction`，最后一步才化成小数。这一点很重要：一个把 `1/3` 印成 `0.33` 再自称"推导"的教学仓库，犯的正是它要取代的那种毛病。

式子只有一条，动作有四种，四种动作换的是**"成功"这个事件的定义**：

| 动作 | risk（此刻新掏的钱） | reward（成功时净赢的钱） | "成功"是 |
|---|---|---|---|
| 跟注 | `B` | `P + B`（面对你的底池） | 摊牌份额够 |
| 诈唬 | `B` | `P`（对手下注前的底池） | 所有人都弃牌 |
| 3-bet 诈唬 | 加注新增的部分 | 加注前面对你的底池 | 开池者弃牌 |
| 全下 | 身后全部筹码 | 看分支：弃牌 / 被跟 | 两个分支各算一次 |

## 推导 / Derivation

**第一条：式子本身。** 设成功概率 `p`，失败 `1 − p`：

```
EV = p·reward − (1 − p)·risk = 0
p·reward + p·risk = risk
p = risk / (risk + reward)
```

三行，没有别的前提。它也不要求你懂 poker——它只要求"两种结局"。这一点会在"何时失效"里咬你一口：只要存在第三种结局（平分底池），`p` 就必须是**份额**而不是"赢的概率"。

**第二条：跟注。** 站在你决策的那一刻，底池面对你的钱是 `F = P + B`（`P` 是对手下注前的底池，`B` 是对手刚加进去的下注）。你跟注要多掏 `B`，最终底池 `F + B = P + 2B`。于是

```
risk = B,  reward = F = P + B
break-even = B / (B + P + B) = B / (P + 2B)
```

这正是 `equity_needed_to_call`。两者在同一条输入上返回同一个数，可当作自检：`break_even_percentage(2.17, 6.5 + 2.17)` 与 `equity_needed_to_call(6.5, 2.17)` 都给出 `0.200184501845…`，即 **20.02%**。

**第三条：诈唬。** 你下 `B` 进 `P`。成功（所有人都弃）你净赢 `P`；失败你净付 `B`。

```
break-even = B / (B + P) = required_fold_frequency
```

`P = 6, B = 2`（1/3 池）时是 `1/4`，即 **25.00%** 的弃牌率；`P = 13, B = 6.5`（半池）时是 **33.33%**。注意 `reward` 是 `P` 不是 `P + B`：你诈唬成功时拿回的 own bet 不属于"赢下的钱"。**这就是同一条式子在两个方向上的唯一区别**——跟注时对手的钱在池里（`reward = P + B`），诈唬时你的钱刚进池（`reward = P`）。

**第四条：3-bet 诈唬。** 场景：BTN 开池 2.5，你在 BB（已投 1）。底池面对你 = 3.5。你 3-bet 到 8，也就是**新增** 7（不是 8：那 1 个盲注早就在池里，它不是你此刻的风险，它已经是底池的一部分）。

```
break-even = 7 / (7 + 3.5) = 66.67%
```

这个 66.67% 是"需要开池者弃牌的比例"。它和第 2 条的 25%（面对 1/3 池跟注需要的胜率）不是同一类东西，一个是频率要求，一个是份额要求——`02-03` 会把这条界线当成主要内容。

**第五条：全下。** 底池面对你 `F = 6`，你身后 `S = 10`。同一式子，两种结局定义各算一次：

```
只算弃牌分支： break-even = S / (S + F) = 10/16 = 62.50%   ← 需要对手弃牌
被跟之后：      e ≥ S / (F + 2S) = 10/26 = 38.46%          ← 需要摊牌份额
```

第二个式子就是 `all_in_equity_needed(pot=6, stack=10)`，也等于用 SPR 写的 `SPR/(1+2·SPR)`：`python -m pokergto spr --stack 10 --pot 6` → SPR 1.667 → 0.3846。同一件事的第三种写法，三个数互相咬合。

**第六条：钱的归属，只有一条判据。** 从决策点往前看：

- **你此刻要新掏的钱 = risk。**
- **你成功时赢下的池子 = reward**，它包含对手投进来的一切，也包含你自己**早前**投进去的死钱——因为那些钱已经不在你的筹码堆里，它是"被赢走"的东西的一部分。
- **你此刻新掏的钱不是 reward。** 它在你赢的时候回到你手上，那叫回本，不叫赢。

把这条判据违反两次，就得到自我教学派最常见的两个反向漏洞：把已投的死钱再当一次风险（门槛虚高 → **过度弃牌**），或把新掏的钱当一次回报（门槛虚低 → **过度跟注、过度诈唬**）。下一节把两个错误的数字都算出来。

## 直觉 / Intuition

保本百分比不是"我该不该跟"的答案，它是**一条门槛线**：你的份额线在它上面，就跟；在下面，就弃。剩下所有的事情——补牌多少、位置好坏、对手多紧——都是"我的份额是多少"这一侧的问题，不是这一条式子的问题。

一句人话版本：**冒 1 个筹码去赢 4 个筹码的赌博，需要五分之一的成功率**。1/3 池的下注让跟注者冒 1 去赢 4（因为面对他的池子是他要跟的那一注的 4 倍），所以门槛是 20%；同一条下注如果是**你**在诈唬，你冒 1 去赢 3，所以需要 25% 的弃牌率。同一个尺度，两个数字，差别只在"谁的钱已经在池里"。

## 算例 / Worked examples

**例 1 — 小尺度：翻牌圈 1/3 池，`P = 6, B = 2`。**

```
跟注需要：2/(6+4) = 1/5 = 20.00%
诈唬需要：2/(6+2) = 1/4 = 25.00% 的弃牌率
防守地板：MDF = 6/8 = 3/4 = 75.00%（这是 02-03 的内容，此处只做对照）
```

三个数是三个不同的问题：我这手牌要多少份额、我那手空气要多少人弃、我的整个范围要留下多少。三个数都从 `risk/(risk+reward)` 出来，只是 `risk`/`reward` 各自量在谁身上。

**例 2 — 中尺度：转牌圈半池，`P = 13, B = 6.5`。** 跟注需要 **25.00%**。同花听牌在这一街上：只看一张牌 `9/47 = 19.1489%`，看两张牌 **34.9676%**。所以决定权在"你还拿几张牌"：转牌圈（后面还有河牌）过线，河牌圈（只剩摊牌）不可能靠补牌过线。若你在转牌圈只允许自己算一张牌，要让跟注打平，需要未来再多赢

```
6.5 / 0.191489 − (13 + 13) = 7.94 个筹码
```

代回 `implied_odds_break_even_equity(13, 6.5, 7.9444)` 得到 19.1489%——这是隐含赔率的精确形式，也是 `02-02` 的主题：那个 7.94 是**假设**，不是计算。

**例 3 — 大尺度：`F = 6` 的池子，身后 `S = 10` 全下。** 弃牌分支要 **62.50%** 的弃牌率，被跟分支要 **38.46%** 的摊牌份额。同一手牌、同一条式子，两个门槛——一个用频率衡量、一个用份额衡量，混用它们的人会在同一个牌面上同时"太松"和"太紧"。

**例 4 — 反解尺度。** 底池 8，你希望自己的诈唬只需要对手弃 60% 就打平，该下多少？解 `B/(8+B) = 0.6` → `B = 12`，即 1.5 倍池。这条反解在每个尺度上都唯一，也正是 `02-03` 里"尺度与防守是同一方程的两边"的另一种写法。

## 实战牌局 / Live hands

**牌局 1（`hand.02-01-turn-flushdraw`）— 转牌圈，底池 13，对手下 6.5（半池），你拿着同花听牌（9 张补牌，无其他出路）。**

门槛：`6.5/(13+13) = 25.00%`。你的份额：一张牌 **19.1489%**，两张牌 **34.9676%**（`draw_probability(9, 47, 1)` / `(9, 47, 2)`，精确）。

- 转牌圈（还剩河牌）：34.97% > 25.00%，跟。**保本数字单独就把结论定下来了**，不需要读任何人。
- 假设这是河牌圈（牌已发完）：不存在"下一张牌"，只能用摊牌份额跟门槛比，补牌式的推理当场失效。
- 若有人在这里说"只算一张牌也得跟，因为可能再赢他 8 个筹码"：那正是例 2 里那个 7.94 的假设版。用 `break_even_percentage` 反解只需一秒，但**这 7.94 会不会真来，本节不算，也标 UNVERIFIED**。

**牌局 2（`hand.02-01-overfold-check`）— 翻牌圈，底池 6.5，对手下 2.17，你在 BB（这一手你已投 1）。你拿着 `J9s` 这个类。**

正确门槛：`2.17/(6.5 + 4.34) = 20.02%`。你实际拥有的份额（对 `88+,ATs+` 精确枚举 1,176 个发展牌序）：`python -m pokergto equity "J9s" --range-villain "88+,ATs+" --board "Kh7s3d"` → **20.16%**。20.16% > 20.02% → 跟注，余量 0.15 个百分点。

现在把最常见的错算一遍：把已经投进去的 1 个盲注再当一次风险，`risk = 3.17, reward = 8.67` → `break_even_percentage(3.17, 8.67)` = **26.77%**。门槛从 20.02% 抬到 26.77%，这手牌立刻变成弃牌。**多出来的 6.75 个百分点不是判断，是重复记账**。反过来，如果把要掏的 2.17 也算进回报（`reward = 10.84`），门槛掉到 **16.68%**，于是你会用一堆负期望的牌跟注。两个方向都是同一件事：钱没有从决策点量。

## 范围图 / Range chart

本节不嵌网格，理由和单位有关。保本百分比是**一手牌对一个数**的门槛（份额 ≥ 门槛），而 13×13 网格画的是**一个类进不进、进多少**的频率。两者唯一的接合点在 `02-03`：那里门槛变成了对整个范围的组合数配额（`MDF = P/(P+B)`，组合数加权）。想先把网格读对，回到 `01-07`：那里的格值分布、图例阈值、以及"覆盖 884.0 组合 = 全 1326 的 66.67%"那一行统计，是任何后续频率讨论的地基。本节能给的只有一句话：**先确定你的百分数是份额、弃牌率还是范围频率，再谈保本。**

## 为何成立、何时失效 / Why it works, when it breaks

**成立的前提**：结局只有两种（赢/输）、钱一次过（这一注之后不再有新决策）、没有第三种结局（平分）、风险中性（筹码与钱线性等价）、没有抽水。

**失效的样子，以及失效时会发生什么**：

1. **存在平分分支。** 保本式里的 `p` 必须是**份额**（`wins + ties/2`），不是"全拿的概率"。用 `01-05` 那个例子衡量：`AcKd` 对 `AdKh` 的份额是 49.63%，其中纯赢只有 1.09%。谁把"保本 20%"读成"要有 20% 的机会全拿"，谁就在给一个不存在的事件定价。
2. **后续街还没结束。** `risk = B` 只在这一注是最后一笔钱时成立。如果跟了这注还要在河牌面对一次 3/4 池，真实风险大于 `B`，门槛被系统性低估。这条的正规处理在 `02-02`（隐含赔率）与第 06 章的行动线。
3. **抽水。** 现金桌的底池要交税，`reward` 实际比面上小一点。本仓库没有 rake 模型（词汇表里 `rake` 归在 `07-04`），因此任何"扣掉抽水后门槛变成 X%"的说法在这里是 **UNVERIFIED / 未核验**——要核验需要一个抽水口径与一手牌的期望值拆解。
4. **锦标赛。** 筹码的效用不是钱，风险中性不成立（第 12 章 ICM）。同一个 25.00% 门槛，在泡沫期对应的正确动作可能不是"份额够就全下"。
5. **多人底池。** 一次诈唬要同时对上多个防守者，`reward` 还是 `P`，但"所有人都弃"的概率不再是单挑的那个频率——`07-01` 用 `d = 1 − (B/(P+B))^(1/N)` 处理这一维。

## 陷阱 / Common mistakes

1. **把已投进池子里的自己那份钱再算一次风险。** `risk = B + 自己的死钱`：`P = 6.5, B = 2.17` 时门槛从 20.02% 抬到 **26.77%**。
   *代价*：这是自我教学派过度弃牌（`overfold`）最常见的算术来源。它稳定地把 20%–27% 之间那一整段份额的牌从"该跟"推到"该弃"——牌局 2 那手 `J9s`（20.16%）就是被吞掉的那一类。
2. **把此刻要新掏的钱算进回报。** `reward = P + 2B`：门槛掉到 **16.68%**。
   *代价*：方向相反，同样贵。你会用 17%–20% 的份额去跟 1/3 池，每一手都在负期望；而且因为它是"回本"混进"盈利"，你不会从结果里看出破绽。
3. **用赢面衡量保本份额。** 只看纯赢率，不看平分。
   *代价*：`AcKd`/`AdKh` 那手 49.63% 份额被读成 1.09% 纯赢——你会以为自己是空气。反过来在听牌上你会低估自己（同花的 chop 分支被吞）。永远读 `equity` 输出的 `[W.../T...]` 拆解。
4. **把诈唬需要的弃牌率当自己拥有的弃牌率。** `B/(P+B)` 说的是"要多少人才算打平"，不是"多少人会弃"。
   *代价*：真实弃牌率必须来自一个被说明的样本或一个策略模型（第 13 章的人口统计侧）；本节给的是门槛，不是估计。任何"这个对手 40% 会弃"在这里都算 **UNVERIFIED**，除非写明来源与核验方式。

## 练习 / Drills

- 心算 `1/4, 1/3, 1/2, 2/3, 3/4, 1, 2` 倍池底各自的跟注保本与诈唬保本，用 `python -m pokergto odds --pot 1` 检查：跟注保本看"跟注所需胜率"那一列，诈唬保本看 MDF 那一列的补（`1 − MDF = B/(P+B)`）。
- 底池 10，你身后 15：全下需要多少弃牌率？被跟之后需要多少份额？两个数各是多少，为什么第二个小于第一个？（`python -m pokergto spr --stack 15 --pot 10`）
- 反解：`P = 8` 时多大下注正好需要 60% 弃牌率？（答案 12，即 1.5 倍池，见例 4。）
- 把 `risk = B + 死钱` 与 `reward = P + 2B` 两个错算各写一遍，算出它们相对正确门槛偏了多少个百分点，并说明各自把人推向哪个方向。
- 说出式子里 `reward` 在三种动作下分别指哪笔钱：跟注、诈唬、全下被跟。
