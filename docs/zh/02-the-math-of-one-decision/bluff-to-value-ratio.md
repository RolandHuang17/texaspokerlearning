# 诈唬与价值的配比：无差别条件如何定出比例

<!-- hands: 2 -->
<!-- terms: bluff-to-value-ratio, bluff, value-bet, bluff-range, value-range, indifference, bluff-frequency, alpha, pot, bet, combos -->

## 本节目标 / Objectives

- 能从"抓诈唬牌跟注与弃牌等值"这一个条件，独立推出下注范围里的诈唬份额 `B/(P+2B)`，而不是背一张配比表。
- 给定任意下注尺度，能立刻说出价值组合数与诈唬组合数的配比，并说清它随尺度移动的方向。
- 能反驳"下注越大就越该只放强牌"这个直觉：代数显示大尺度反而要求**更多**诈唬。

## 前置知识 / Prerequisites

- `02-01` 保本百分比：拿 `R` 去博 `W`，需要 `R/(R+W)` 的胜率。
- `02-03` 最低防守频率（MDF）：`P/(P+B)`。本节的推导用的是同一套无差别思路，只是换了被问的人。

## 核心原理 / The principle

河牌圈，底池 `P`，我方下注 `B`。若我方下注范围里有 `V` 个价值组合数、`N` 个诈唬组合数，则诈唬份额

```
b = N / (V + N) = B / (P + 2B)
价值 : 诈唬 = (P + B) / B
```

这是一条 `derived` 结论：它只用到"抓诈唬牌跟注与弃牌一样差"这一个条件，不依赖任何求解器、任何范围表、任何人的权威。

## 推导 / Derivation

先看真实筹码，别先看"底池比例"。设底池 12，我方下注 6。对手手里是一手**只打得败空气**的牌（抓诈唬牌）：对上价值必输，对上诈唬必赢，无平分。

- 他弃牌：拿回 0（按 `02-03` 的约定，池里已有的钱两边都拿不回来，抵消掉了）。
- 他跟注：池子变成 `12 + 6 + 6 = 24`。他赢时从这 24 里拿回自己那 6，净赚 18；输时净赔 6。

设我方下注范围里诈唬的比例是 `b`，跟注的期望值：

```
EV(call) = b·18 − (1 − b)·6
无差别：b·18 = (1 − b)·6
        24b = 6
        b = 6/24 = 0.25          ← 25% 的诈唬
```

换成一般记号：赢时净得 `P + B`，输时净赔 `B`，于是

```
b·(P + B) − (1 − b)·B = 0
b·(P + 2B) = B
b = B / (P + 2B)
```

**为什么"底池比例"这个约定不会改变答案**：把 `P` 和 `B` 同时乘以任意 `k > 0`，

```
kB / (kP + 2kB) = B / (P + 2B)
```

`k` 被约掉了。所以 12 与 6 的牌局、和 `P = 1` 与 `B = 0.5` 的记号，给出同一个 `b = 25%`。约定只是把筹码单位换成底池单位，它不动任何结论——这也是本仓库能把一张尺度表用在任意筹码深度上的原因。

再由 `b` 得到配比：

```
价值 : 诈唬 = (1 − b) : b = (P + B) : B
```

注意 `b` 和 `02-02` 的"所需胜率"是**同一个表达式** `B/(P+2B)`。这不是巧合：诈唬份额就是让抓诈唬牌无差别所需的那个胜率。差别只在它回答谁的问题——份额回答"我该放多少空气"，胜率回答"我这手牌够不够格跟"。

## 直觉 / Intuition

把配比读成一句话：**每一手价值下注，都得带上一定配额的诈唬当护卫；尺度越大，护卫要得越多。**

- 1/3 池：护卫比 1 : 4，即 4 手价值带 1 手空气。
- 底池：护卫比 1 : 2，2 手价值带 1 手空气。
- 2x 池：护卫比 2 : 3，3 手价值要带 2 手空气。

为什么方向是这样的？因为你的大注需要对手**敢跟**才有价值。他敢不敢跟，取决于他判断你有多少空气。你要是只用强牌下大注，他弃掉全部中等牌，于是你的强牌只能赢下一个小小的底池 `P`，赢不到 `P + B`——大注的价值收入反而断了。要让他跟注，你必须在范围里装足够多的空气；空气越多的尺度，你才越付得起。

反过来看小注：1/3 池只要求你 20% 的诈唬，因为对手跟这个注只需要 20% 胜率，他很乐意跟，你的价值收入本来就来自"更差的牌愿意跟小注"。这时你几乎不需要护卫，反而是护卫的配额很便宜。

所以"大注＝强牌＝紧"这个直觉把两件事混成了一件：大注确实只该用**一部分**牌去打，但那一部分里必须有相当高比例的空气。

## 算例 / Worked examples

**例 1 — 1/3 池，`P = 12, B = 4`。** `b = 4/(12+8) = 20%`，配比 `16/4 = 4 : 1`。
若你的价值段有 24 个组合数（`QQ,JJ,TT,99`，用 `poker range "QQ,JJ,TT,99"` 查到 24），那你最多只能带 `24/4 = 6` 个诈唬组合数。

**例 2 — 底池，`P = 20, B = 20`。** `b = 20/60 = 33.33%`，配比 `40/20 = 2 : 1`。
同样 24 个价值组合数，这里可以带 12 个诈唬组合数。是例 1 的两倍。

**例 3 — 2x 池超池下注，`P = 20, B = 40`。** `b = 40/(20+80) = 40%`，配比 `60/40 = 1.5 : 1`。
24 个价值组合数要配 16 个诈唬组合数。**这是本节最重要的一行**：尺度从 1/3 池涨到 2x 池，风险变成 6 倍，但你的范围必须变得更"松"，不是更紧。

**例 4 — 反过来问"我能打多大"。** 假设河牌上你只有 4 个组合数适合诈唬（错过同花的那些起手同花牌）。`b = B/(P+2B) ≤ 4/(4+24) = 1/7 ≈ 14.29%`。
解 `B/(P+2B) = 1/7` 得 `B = 0.2P`，即**五分之一池**。核对：`poker odds` 的 `equity_needed_to_call(1, 0.2)` 正好给出 `0.142857`。也就是说，24:4 的价值结构最多撑得起 1/5 池的下注；引擎的标准尺度阶梯里最小的 1/4 池都要求 16.67%，你已经付不出这个配额。

**例 5 — 与 MDF 并排核对。** 底池下注：`MDF = 20/40 = 50%`，配比 `2 : 1`。这两个数字来自同一个无差别条件，但一个是被防守方的频率、一个是下注方的构成，别把它们填进同一列。

## 实战牌局 / Live hands

**牌局 1（`hand.02-04-river-over-bluff`）— 单挑，河牌 `AcKd8s5h2c`，底池 20，我方下注 20（底池）。**

我方下注范围：价值 `QQ,JJ,TT,99` = 24 个组合数（`poker range "QQ,JJ,TT,99"` 给出 24），诈唬 `JTs,T9s,98s,QJs,T8s` = 20 个组合数（`poker range "JTs,T9s,98s,QJs,T8s"` 给出 20）。

- 实际诈唬份额 = `20/44 = 45.45%`；底池下注要求的份额 = `33.33%`。**超了 12.12 个百分点。**
- 后果可以精确算出来：对手的 `KsQs` 这类抓诈唬牌（只打得败那 20 个诈唬组合数）跟注的期望值，用引擎算是
  `PYTHONPATH=src python -c "from pokergto.ev import ev_call; print(ev_call(20,20,20/44))"` → `7.2727` 个筹码。
  配比正确时（24 价值 + 12 诈唬，份额 `1/3`）同一行命令传入 `12/36` → `0.0`。
- 也就是说，多出来的 8 个诈唬组合数把对手一手"本来恰好无差别"的牌变成了每手净赚 7.27 的白送。他不是靠读牌打赢你的，是靠你的配额超支。
- 修正有两条路。第一条：把诈唬砍到 12 个组合数，保留那些最能阻断对手跟注范围的起手牌。第二条：反过来问"要多大的尺度，才让 20 个诈唬恰好合规"，解 `B/(20+2B) = 20/44` 得 `B = 100`，也就是 5 倍池——比 2x 池的阶梯顶端还大一倍多，实战里不是一个能用的尺度。所以对本手牌而言，只有砍空气（或加价值）这一条出路。方向也别搞反：**超配之后要靠更大的尺度去消化，不是靠更小的尺度**，只是代价高到不可行。

**牌局 2（`hand.02-04-value-heavy-small`）— 同一张河牌，底池 20，我方价值厚而空气少。**

价值仍是 24 个组合数，但能拿来诈唬的只剩 `T8s` 的 4 个组合数。

- 份额 `4/28 = 14.29%`。查例 4：这撑得起的最大尺度是 1/5 池。
- 于是这个范围应该做两件事：价值段下**小注**，诈唬段大部分过牌。理由不在"小注更安全"，而在所需胜率：更差的牌要跟注，需要 `B/(P+2B)` 的胜率；你把 `B` 从 1/4 池涨到底池，这个门槛从 16.67% 涨到 33.33%，而你能提供的诈唬份额只有 14.29%，于是所有比你差的牌都能干净地弃牌。你的价值收入被自己关在门外。
- 反过来看 1/5 池：门槛正好等于 14.29%，比你差的牌无差别，你才有机会收到 `P + B`。
- 结论："我有好牌所以要下大注"在本节的代数里是错的。下注尺度先由**你的空气配额**决定，再由牌力决定用哪些价值去配它。

## 为何成立、何时失效 / Why it works, when it breaks

成立的前提：**河牌圈**（没有后续牌会改变牌力）、**单一决策点**、对手的抓诈唬牌要么全胜要么全败（无平分）、双方都按最优化反应行动。

它在这几种情形下不再是你该直接执行的数字：

1. **还没到河牌。** 半诈唬在下一条街有赢的方式，它不该被算进 `N`。翻牌圈与转牌圈的配比要连任意街改进一起算，那是第 04 章（`04-06` 半诈唬）的内容。
2. **防守方会加注。** 本节的 `−B` 假设"被跟注就输 `B`"。若对手加注、你弃牌，你输的还是 `B`，所以对纯空气这一条不变；但范围里的中等牌会因此改变归属，配比要重算。`02-08` 处理这件事。
3. **有平分。** 胜率按定义含半份池（`equity` 词条写作 `e = P(赢) + ½·P(平分)`），出现 `AA` 撞 `AA` 这类摊平时 `b` 会略有偏移；本节的封闭解忽略它。
4. **你有多个尺度可用。** 配比是**按尺度**成立的：同一手牌在 1/3 池与 2x 池两条线里属于不同的子范围。一条范围只能有一个配比的时代，是尺度集合只有一个的年代。
5. **对手防守不足或过度。** `b` 是"不被剥削"的构成，不是"最多赚"的构成。对手弃牌过多时，正确做法是超出配额诈唬（第 13 章的剥削线）；这与你该不该学这一节不冲突——先有基准，再谈偏离。

关于**极化 / 合并**范围形状的预告：正因为大尺度要付得起空气配额，实战里大注常与"顶端价值 + 底端空气"的极化形状一起出现，小注常与把中等牌一起装进来的合并形状一起出现。本节不证明这一点。它是 `04-05` 的结论，来源类型应为 `derived`（一街玩具博弈的尺度选择 + 牌型容量约束）。在此之前，这条属于 **UNVERIFIED / 未核验**，验证路径：`src/pokergto/theory/` 的尺度推导 + 第 08 章两街玩具博弈复现。

## 陷阱 / Common mistakes

1. **把 MDF 那一列当成配比那一列。** 1/3 池：`MDF = 75%`、诈唬需要的弃牌率 `25%`、诈唬份额 `20%`、配比 `4 : 1`。同一行里 25% 与 20% 只差五个百分点，抄错一列就换了一个含义：前者是**对手**该弃的比例，后者是**你**范围里空气的占比。（顺带一提，`跟注所需胜率` 也是 20%，因为它与诈唬份额是同一个表达式。）
   *代价*：你以为"对手弃 25% 我就该诈唬 25%"，于是每 3 手价值带 1 手空气（配比 3:1），实际要求是 4:1。多出的空气在底池下注那一行会把手上的抓诈唬牌从 0 期望推到 +7.27（见牌局 1）。用 `poker odds --pot 1` 一次把四列打出来，比背表可靠。
2. **以为大注意味着范围更紧。** 2x 池要求 40% 的诈唬份额，是所有标准尺度里最高的。
   *代价*：用"只打强牌"的 2x 池范围，对手对中等牌一律弃牌，你的强牌从此只赢 `P`、永远赢不到 `P + B`；同时你的空气一旦被抓就输 2 倍池。这是双重亏损，而它源于一个方向搞反的直觉。
3. **手数牌类别而不是组合数。** `AKo` 12 个组合数、`AKs` 4 个、`AA` 6 个（`table.01-01.combo-decomposition`）。
   *代价*：3 类价值配 1 类诈唬看着像 3:1，实际组合数是 18:4 = 4.5:1，你的配额是超支还是不足，用类别数根本判断不出来。凡配比问题先换算成组合数，再用 `poker range "..."` 核对。
