# 矛头防守频率：为什么是 pot/(pot+bet)

<!-- hands: 2 -->
<!-- terms: mdf, pot, bet, fold, call, bluff, value-hand, equity, combos, range -->

## 本节目标 / Objectives

- 能从"纯诈唬的下注必须无差别"这一条出发，独立推出 `MDF = pot/(pot+bet)`，而不是背下它。
- 给定任意下注尺度，能立刻算出对手至少要多频繁地继续，以及自己诈唬需要的弃牌率。
- 能说清 MDF 约束的是**频率总量**，不告诉你**用哪些牌**去达到它——并知道这个缺口在哪里被剥削。

## 前置知识 / Prerequisites

- `02-01` Break-even percentage：一次赌博需要的胜率 = 风险 /(风险 + 回报)。
- `02-02` Pot odds to call frequency：底池与下注之间的代数关系。

## 核心原理 / The principle

面对一次下注，防守频率的下界是

```
MDF = pot / (pot + bet)
```

其中 `pot` 是对手下注**之前**底池里的钱，`bet` 是对手新增的下注。这是一条 `derived` 结论：它由"纯诈唬必须无差别"这一个条件推出，不依赖任何 solver、任何人的表、任何经验。

## 推导 / Derivation

设底池为 `P`，对手下注 `B`。考虑对手用一手**永远不可能赢**的牌（纯空气）诈唬。

- 你弃牌（含所有防守者都弃牌）的概率记作 `f`。此时对手不冒任何风险就拿走底池：收益 `+P`。
- 你防守的概率 `1 − f`。空气牌被跟注就是输：收益 `−B`。

无差别条件（诈唬的期望收益为 0）：

```
f·P − (1 − f)·B = 0
f·(P + B) = B
f = B / (P + B)                    ← 诈唬所需要的最低弃牌率
```

于是防守方必须继续的频率就是它的补：

```
MDF = 1 − f = 1 − B/(P+B) = P/(P+B)
```

这一步没有引入任何新假设：它只是把同一条等式从"诈唬者"侧翻到"防守者"侧。**这正是 MDF 与"跟注所需胜率"容易被混为一谈的原因：前者是弃牌率的补，后者是 `B/(P+2B)`，两个不同的东西。**

防守不足会被惩罚：若对手在 `P = 1, B = 0.5` 时只防守 50%（低于 `MDF = 66.7%`），他任何两张牌的空气下注都是 `0.5·1 − 0.5·0.5 = +0.25` 的赚钱动作——与拿的是什么牌无关。

## 直觉 / Intuition

把 MDF 读成一句人话：**"我弃掉的比例，不能超过让你的空牌也赚钱的临界点。"**

- 对手下得越小，`B/(P+B)` 越小，他诈唬需要的弃牌率越低，因此你必须防守得越多（1/3 池 → 75%）。
- 对手下得越大，他必须放弃越多才能骗到你（2x 池 → 只需你弃 33%），因此你必须防守得越少。
- 尺度与防守是**同一方程的两边**。这不是"激进 vs 被动"的品味问题，是算术。

心智模型：MDF 是一条地板线。你可以在它上面任意建造（用强牌加注、用听牌跟注、用同花底牌跟），但一旦低于它，你就不再是在做决定，而是在给对手印钱。

## 算例 / Worked examples

**例 1 — 翻牌圈 1/3 池下注。** `P = 6.5`（底池），`B = 2.17`。
`MDF = 6.5 / 8.67 = 0.75`。也就是说这一手牌里，你 1326 个起手组合对应的这个防守范围里，**至少 75% 的组合数必须继续**（跟或加）。剩下最多 25% 可以弃。

**例 2 — 转牌圈底池下注。** `P = 12, B = 12`。`MDF = 12/24 = 0.50`。
如果这里你只防守 40%，对手的空气下注每手的期望是 `0.6·12 − 0.4·12 = +2.4`：他不用看牌，只要下注就赚 2.4 个注码。

**例 3 — 河牌 2x 池超池下注。** `P = 20, B = 40`。`MDF = 20/60 = 0.333`。
这条常被误解为"超池下注很可怕"。真相是：对手用 2x 池诈唬需要你先弃掉 66.7% 才赚钱；如果你防守到位，他必须用真正能赢的牌才敢下这个尺度。你的工作不是判断"他敢不敢"，而是**把防守频率守在 33.3%**。

**例 4 — 与"跟注所需胜率"对照。** `P = 10, B = 5`：
`MDF = 10/15 = 66.7%`，而跟注需要的胜率是 `5/(10+2·5) = 25%`。
一个是"我的范围要有多少比例继续"，一个是"我这手牌要多少胜率才值得继续"。**同一局面里的两个不同问题**，混淆它们是自我感觉派最常见的算术错误。

## 实战牌局 / Live hands

**牌局 1（`hand.02-03-c-bet-defense`）— 现金 6 人桌，CO 开池 2.2x，BTN 跟注，翻牌 `Kh7s3d`，CO 下注 1/3 池。**

你在 BTN，拿着 `Jd9d`（两头顺听牌 + 两张高牌，6 张补牌 + 一些后门）。底池 6.5，对手下 2.17。

- 尺度上：`MDF = 75%`。BTN 面对 CO 的持续下注，范围里必须留下 75% 的组合继续。
- 单手上：跟 2.17 进 8.67+2.17，需要胜率 `2.17/10.84 = 20.0%`。`Jd9d` 对 CO 的价值+诈唬混合范围大约在 24–30%（用 `poker equity "Jd9d" "88+,ATs+" --board "Kh7s3d"` 自己算），因此这一手轻松过线。
- 决策：跟注。不是因为"听牌好看"，而是因为需要的胜率与拥有的胜率之间有可测量的余量。

**牌局 2（`hand.02-03-river-overbet`）— 单挑，河牌 `AsKd7h5c2s`，对手超池下注 2x。**

底池 20，对手下 40。你拿着 `JhTh`（一对都没有，只赢对手纯诈唬）。

- `MDF = 20/60 = 33.3%`：你的范围必须有三分之一继续。
- 你的牌属于"只击败空气"的 bluff-catcher：正好是决定对手诈唬是否赚钱的那类牌。所以**它必须留在防守范围的靠前部分**，否则你的 33.3% 会由更差的牌承担，而 `JhTh` 弃掉就是把自己的防守配额让给了更弱的组合。
- 需要的胜率 = `40/(20+80) = 33.3%`，即对手的诈唬比例必须达到下注范围的三分之一才值得跟。这与 `sizing_table` 里 2x 池那一行的 40% 诈唬占比相减，就是你的边际——正号，跟注。

## 为何成立、何时失效 / Why it works, when it breaks

**成立的前提**：双方都用最优化反应、对手会惩罚任何低于地板的防守、并且"弃牌"这个动作的价值就是放弃底池。

它在这几种情形下**不再是你应该直接执行的目标**：

1. **多人底池。** 诈唬要成立需要**所有人**都弃牌。若每名对手独立地以 `d` 防守，需要 `(1 − d)^N = B/(P+B)`，所以
   `d = 1 − (B/(P+B))^(1/N)`。指数是 `1/N`：N=1 时回退到本节公式（这是它的自校验）。N=2、底池下注时每人只需防守 29.3%，但合并防守仍是 50%。**结论：多人局面下"每人防守频率"下降，"整桌防守频率"不变。** 详见 `07-01`（并请注意：合并公式假设防守者相互独立，牌力移除会让真实值偏离）。
2. **跟注方有再加注时。** MDF 是对"跟或弃"这个二择一动作的推导。如果防守方可以加注，惩罚机制部分转移到加注上，跟注频率可以更低——但**总防守频率**的地板不变。这是初学者在 solver 图上最常见的误读。
3. **风险厌恶（锦标赛）。** 筹码的效用不是线性的。接近钱圈时，`MDF` 的"正确"频率会让你在输掉硬币 flip 后被淘汰，此时按 ICM 定价的防守频率**低于** MDF 是理性的（对手的空气反而能赚钱，你主动接受它）。第 12 章处理这件事。
4. **对手不会惩罚。** MDF 是"防止被剥削"的下界，不是"最大化收益"的选择。如果对手根本不诈唬，低于 MDF 的防守不会损失任何钱，反而省下了输给出牌的钱。对大众倾向的偏离属于第 13 章。
5. **牌力移除。** 上面多人公式假设独立，真实发牌里对手的牌与你的牌相互约束（你的方块减少他能有的同花），因此它是一个近似。本仓库在数据里把这条写进 `provenance.assumptions`，不把它藏起来。

## 陷阱 / Common mistakes

1. **把 `MDF` 当成"跟注所需胜率"。** 两者分母不同：`P/(P+B)` 与 `B/(P+2B)`。
   *代价*：在 1/3 池尺度上，正确防守是 75%，而"我只要 25% 胜率就跟注"会被误当成"我可以弃掉 75%"。用 `poker mdf --pot 6 --bet 2` 与 `poker odds` 各算一次，一分钟就能把这个混淆彻底拆开。
2. **只用一手牌的胜率去判断整个范围是否达标。** MDF 是**组合数加权**的，不是"手牌类"加权的：`AKo` 有 12 个组合、`AKs` 有 4 个、`AA` 有 6 个。按 169 类平均会让你的估算系统性偏离。
   *代价*：一个"看起来防守了 70%"的范围，按组合数加权可能只有 55%，被对手用任意两张牌诈唬——每手 +0.15 个底池份额的稳定收入。用 `poker range "22+,ATs+"` 看组合数就明白差距。
3. **在多人底池里延用单挑 MDF。** 每人 50% 的防守在 3 人底池里意味着合并防守 `1 − 0.5² = 75%`，你超额防守了 25 个百分点，被价值下注白吃。
   *代价*：见 `07-01` 的生成表；量级足以让一个"稳健"玩家在多人底池里长期净负。

## 练习 / Drills

- 心算：`1/4, 1/3, 1/2, 2/3, 3/4, 1, 1.5, 2` 倍池底的八档尺度，各自的 `MDF` 与诈唬所需弃牌率。用 `poker odds` 检查。
- 4 人底池，`P = 24, B = 12`：每人需要防守多少？（提示：`1/2` 的立方根，不是 `1/4`。）
- 反推：若对手在底池 10 上的下注需要你有 45% 的防守才不赚钱，他的尺度是多少？
