# 底池赔率翻译成跟注：所需胜率与隐含赔率的适用边界

<!-- hands: 2 -->
<!-- terms: pot-odds, required-equity, implied-odds, reverse-implied-odds, break-even-percentage, minimum-defense-frequency, defend, fold-frequency, bet-size, outs, equity, spr -->

## 本节目标 / Objectives

- 能用两条完全不同的思路（风险/回报，与"最终底池里我该占多大一份"）推出同一个跟注门槛 `B/(P+2B)`，并说明它们为什么必然是同一个式子。
- 能把"一手牌需要的胜率"和"整个范围需要的防守频率"放在一张表里对照，指出它们随尺度移动的方向相反、并且在约 1.618 倍池底处相交。
- 能正确使用 `pot_odds` 的输出（它是 `P/B`，不是"含你跟注的池子对跟注"），并说出用错分母会偏多少。
- 能算出隐含赔率把门槛压到哪里、反向隐含赔率把门槛抬到哪里，并且说出引入 `future` 时必须额外声明的前提是哪几条。

## 前置知识 / Prerequisites

- `02-01` 保本百分比：`risk/(risk+reward)`，以及"钱要从决策点量"这条判据。
- `01-06` 名义胜率与实现率：门槛比的是**份额**，份额只是可算的那一半。

## 核心原理 / The principle

面对一次下注，跟注需要的胜率是

```
equity needed = B / (P + 2B)
```

`P` 是对手下注**前**的底池，`B` 是对手加进去的下注。它是 `pokergto.odds.equity_needed_to_call`，也和 `break_even_percentage(B, P + B)` 逐位相同。

本节要钉住的对照是：**这个数不是最低防守频率（MDF）**。同一个局面里

```
MDF = P / (P + B)
```

移动方向相反：尺度越大，跟注所需胜率越高（2 倍池 → 40.00%），而 MDF 越低（2 倍池 → 33.33%）。两条线在 `B/P = φ = (1+√5)/2 ≈ 1.618` 处相交，交点值 `2 − φ ≈ 38.20%`——这一条在本节第四段推导。

## 推导 / Derivation

**推法一：风险/回报。** 沿用 `02-01` 的判据：`risk` 是你此刻新掏的钱 `B`；`reward` 是你成功时赢下的池子，即面对你的 `P + B`（对手刚下的 `B` 已经在池里，它属于可赢的钱）。

```
break-even = risk/(risk + reward) = B / (B + P + B) = B / (P + 2B)
```

代入 `P = 13, B = 6.5`（半池）：`6.5/26 = 1/4 = 25.00%`。

**推法二：最终底池里的那一份。** 你跟注之后，底池变成 `P + 2B`。设你的摊牌份额是 `e`（份额的定义见 `01-05`：`wins + ties/2`），那么从决策点算起的期望是

```
EV = e·(P + 2B) − B
EV ≥ 0  ⟺  e ≥ B/(P + 2B)
```

两条推法得到的是同一行代数：`e·(P+2B) ≥ B` 与 `B/(B + (P+B))` 是同一个不等式。这不是巧合——"你至少要在最终底池里占回你投入的那一份"和"你的风险对回报之比就是门槛"，本来就是**同一件事的两种记账方式**。把两条推法都写出来，是因为它们各自会在不同的错误里救你：第一条防"回报量错"，第二条防"份额与赢面混用"。

**第三条：`pot_odds` 的输出是 `P/B`，别把它当成经典的"含你跟注的赔率"。** 引擎里 `pot_odds(pot, bet) = pot/bet`，用的是**下注前**的底池。由它换算门槛：

```
equity needed = 1 / (pot_odds + 2)
```

半池时 `pot_odds(13, 6.5) = 2.0`，门槛 `1/(2+2) = 25.00%` ✓。若按熟悉的 `1/(odds+1)` 去算，会得 `1/3 = 33.33%**——凭空多要 8.33 个百分点，而且这个错误只会让你弃更多牌。差的那个 1 就是"你自己刚掏的那一注"：它进最终底池，但不进 reward。

**第四条：门槛与 MDF 的交点。** 令两者相等，用 `s = B/P`：

```
1/(1+s) = s/(1+2s)  ⟹  1 + 2s = s + s²  ⟹  s² − s − 1 = 0  ⟹  s = (1+√5)/2 = φ ≈ 1.618034
```

在这个尺度上，`MDF = 1/(1+φ) = 38.1966%`，`equity needed = φ/(1+2φ) = 38.1966%`，第 12 位才因浮点表示而分开。数值核对：`mdf(1, φ)` 与 `equity_needed_to_call(1, φ)` 分别给出 0.3819660112500109 与 0.3819660112501411。`φ` 与 `2 − φ` 属于公开数学，不是任何人的结论；这条交点的意义在于**它把"MDF 是门槛的补"这个流行误解彻底否掉了**：两条线只在一点相遇，其余地方一个升一个降。

| 尺度 | 跟注所需胜率 | MDF |
|---|---|---|
| 1/3 池 | 20.00% | 75.00% |
| 1/2 池 | 25.00% | 66.67% |
| 1 倍池 | 33.33% | 50.00% |
| 1.618 倍池 | 38.20% | 38.20% |
| 2 倍池 | 40.00% | 33.33% |

（除交点那一行之外，这张表里的每个百分数都能在本节下面两张生成表里逐行对上。）

**第五条：隐含赔率改的是分母，反向隐含赔率改的是分子。** `pokergto.spr` 的两个式子：

```
隐含赔率：   e ≥ B / (P + 2B + future_winnings)
反向隐含：   e ≥ (B + future_losses) / (P + 2B)
```

在 `P = 6, B = 3`（半池）上，门槛本来 25.00%：

| 前提 | 需要的胜率 | 相对 25.00% |
|---|---|---|
| 未来能再赢 5 | 13.6995% | 低 11.30 个百分点 |
| 未来能再赢 20 | 7.0363% | 低 17.96 个百分点 |
| 未来要再付 3 | 50.0000% | 高 25.00 个百分点 |

一个方向把 `future` 加进分母，另一个方向把它加进**分子**——所以"反向隐含赔率很贵"不是形容句：`f = B` 时门槛正好翻倍（`(B+B)/(P+2B)`，`P = 2B` 时是 `2B/4B = 1/2`）。

**第六条：`future` 的上界可以算，`future` 本身不能。** 后续街最多能搬动身后那么多钱。9 张补牌、只看下一张牌（`draw_probability(9, 47, 1) = 19.1489%`）时，要在 `P = 6, B = 3` 打平需要

```
3 / 0.191489 − (6 + 6) = 3.67 个未来筹码
```

如果身后只剩 3.25，最好的情况也只是 `implied_odds_break_even_equity(6, 3, 3.25) = 19.6721%` 的门槛——**仍然高于你拥有的 19.1489%**。同一种算式也给出关钱的价位：`python -m pokergto spr --stack 3.25 --pot 6` → SPR 0.542 → 全下需要 26.00%（`all_in_equity_needed(pot=6, stack=3.25)` 与 `all_in_equity_needed_from_spr(spr(3.25, 6))` 都给 0.26，两种写法互相咬合）。结论：筹码结构决定隐含赔率值不值钱，而"对手会不会付"永远不是本节能算的。

## 直觉 / Intuition

门槛回答的是"**这手牌**值不值一注"；MDF 回答的是"**我的整个范围**要留下多少"。它们是同一局面的两个问题，而且方向相反：对手下得越大，你越容易用一手好牌找到理由（40% 就能跟 2 倍池），也越有理由放弃范围的大部（只需守 33.33%）。把这两件事混起来的人会说"2 倍池所以我得弃 60%"，然后被价值下注一直压。

听牌的门槛要跟着"你还拿几张牌"走：19.15%（一张）与 34.97%（两张）之间差 15.82 个百分点，正好够把同一个半池决定从"弃"翻到"跟"。先对齐牌的张数，再谈门槛，否则两个正确的数字会吵起来。

## 算例 / Worked examples

**例 1 — 半池，整数好核对：`P = 13, B = 6.5`。** 门槛 `6.5/(13+13) = 25.00%`；`pot_odds = 2.0`，用 `1/(2+2)` 复核同一个数；MDF `13/19.5 = 66.67%`。9 张补牌：两张牌 34.9676% → 过线；只看转牌 19.1489% → 不过线，需要 7.94 个未来筹码才补齐（`6.5/0.191489 − 26`）。

**例 2 — 1/3 池：`P = 6, B = 2`。** 门槛 `2/10 = 1/5 = 20.00%`；MDF `6/8 = 3/4 = 75.00%`；诈唬所需弃牌率 `2/8 = 1/4 = 25.00%`（`02-01`）。三个数在同一条下注上，各答各的问题。

**例 3 — 反解尺度。** 底池 10，你希望门槛正好是 30%，对手该下多少？解 `B/(10+2B) = 0.3` → `B = 7.5`，正好 3/4 池；生成表里 3/4 池那一行的确是 30.00%。

**例 4 — 交点。** `B = 1.618 × P`：门槛 38.20%，MDF 38.20%。这条之上"越大的下注越难跟但也越可以弃"；这条之下"越小的下注越好跟但也越必须守"。这是本节最重要的一张图的形状来源，也是 `02-03` 讨论"频率配额"的起点。

## 实战牌局 / Live hands

**牌局 1（`hand.02-02-margin-of-015`）— 翻牌 `Kh7s3d`，底池 6.5，CO 下 2.17（约 1/3 池），你在 BTN 拿着 `J9s` 这个类。**

- 门槛：`2.17/(6.5 + 4.34) = 20.02%`（`equity_needed_to_call`，也等于 `break_even_percentage(2.17, 8.67)`）。
- 份额：`python -m pokergto equity "J9s" --range-villain "88+,ATs+" --board "Kh7s3d"` → 精确 **20.1649%**（1,176 个发展牌序，`ties` 那一栏 0.00%）。
- 决策：跟注，余量 **+0.15 个百分点**。这不是"听起来还行"，这是两个可复算的数字相减。
- 频率层完全是另一回事：同一尺度 `MDF = 6.5/8.67 = 74.97%`——你的**范围**要留下约 75% 的组合数，而这一手牌只要求 20.02% 的份额。`02-03` 处理这条边界。

**牌局 2（`hand.02-02-payoff-flip`）— 转牌（`Qh9h2s` 之后），底池 13，对手下 13（池底），你拿着 `AhJh`（同花听牌加两张高牌）。**

- 份额：翻牌圈算过的是 46.5657%（`01-06`）；这里用转牌圈的门槛比。池底门槛 `13/(13+26) = 33.33%`，46.57% > 33.33% → 单看"这一注关上门"是跟。
- 但如果你的牌不中、而对手在河牌再下一注重注，你就要多付 13：`reverse_implied_odds_penalty(13, 13, 13) = (13+13)/(13+26) = 66.67%`。门槛从 33.33% 抬到 66.67%，你的 46.57% 当场不够。
- 反过来，如果对手是那种"转牌下、河牌过牌"的范围，你就少付：`implied_odds_break_even_equity(13, 13, 13)`（未来再赢 13）给 **25.00%**，比 33.33% 低 8.33 个百分点。
- 这手牌的教学点不是结论，是**前提**：上面三个门槛对应三个不同的行动线假设。要选哪一个，需要被说明的来源（你自己的计划、第 06 章的行动线、或第 13 章的人群倾向）；`future` 不是引擎能算的东西。

## 为何成立、何时失效 / Why it works, when it breaks

**门槛成立的前提**：只有一个决策点（这一注之后钱就关上或你弃掉）、结局按份额衡量（平分已经被 `ties/2` 计进去）、对手不会在你跟注后再加一层（那属于反向隐含那一支）、筹码与钱线性等价。

**引入 `future` 时必须同时声明的四条前提**（这也是本节标题里"适用边界"的意思）：

1. **对手会在你击中后继续付钱**（隐含那一支）或**会在你落空后不再下注**（反向那一支）。这是策略假设，本仓库不给出任何人的行动频率——要它变成一个数，需要一个被说明的人群模型（第 13 章）或一个已核验的 solver 产物（第 08 章的六个小博弈里没有 6 人桌后翻牌，见 `adr/0002`）。
2. **筹码够。** `future` 有硬上界，就是身后的有效筹码；这一条可算（第六段：需要 3.67、最多 3.25，于是打不平）。
3. **你的份额只在"击中"分支出现。** 若你在落空分支也能赢一点（例如后门、高牌），分母里加的就不该是全部 `future`。
4. **只加一次。** 两街都要付钱的局面里，`future` 是两条街的和，而门槛本身已经在下一街重新变化——把 2/4 法则的"两张牌"折扣和隐含赔率同时用，就是重复计算。

**其他失效场合**：多人底池里门槛的代数形式不变（份额定义不变），但本仓库的 `range_equity` 只打两个范围，所以"三人底池里这手牌的份额"目前没有实现 → **UNVERIFIED / 未核验**；锦标赛里门槛要用 ICM 定价（第 12 章）；抽水不在模型里（`07-04`）。

## 陷阱 / Common mistakes

1. **把 `pot_odds` 当成"含你跟注的赔率"。** 引擎返回 `P/B`（1/2 池时是 2.0），门槛是 `1/(odds+2)` 而不是 `1/(odds+1)`。
   *代价*：`P = 13, B = 6.5` 时正确 25.00%，错算 33.33%——多要 8.33 个百分点，方向是把能跟的听牌全弃掉。核对只需一行：`python -m pokergto odds --pot 1` 看 `pot_odds` 与 `equity_needed` 两列的关系。
2. **把 MDF 与门槛当互补的两个数。** 半池上 MDF 66.67%、门槛 25.00%；两者只在 `B = 1.618P` 相交。
   *代价*：小尺度上你会以为自己可以弃很多（其实必须守 75%–80%），大尺度上你会以为必须守很多（其实可以弃 60%–66%）。`02-03` 的陷阱 1 是同一条错误的另一面。
3. **把隐含赔率当免费的。** 它需要一个上界、一个对手行为假设，以及"份额只在击中分支"的条件。
   *代价*：`P = 6, B = 3` 上 9 张补牌只看一张牌时，永远补不齐——需要 3.67 的未来钱而身后只有 3.25，最好的情况门槛仍是 19.67% > 你拥有的 19.15%。
4. **牌张数不对齐就比大小。** 拿 34.9676%（两张牌）去比"只看转牌"的门槛，或反过来。
   *代价*：15.82 个百分点的口径差，比大多数决策的真实余量都大。先用 `draw_probability(outs, 47, cards_to_come)` 声明张数。
5. **同时用 2/4 法则与隐含赔率。** 一个是份额的近似，一个是份额之上的未来钱；叠在一起就是把同一笔未来赢款算两次。
   *代价*：把明显该弃的牌算成微正期望，且因为误差看起来"不大"而长期不察觉。
