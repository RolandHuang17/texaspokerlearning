# 套池还是收着打：SPR 决定的两种承诺程度

<!-- hands: 2 -->
<!-- terms: pot-commitment, float, spr, effective-stack, shove, required-equity, implied-odds, reverse-implied-odds, decision-plan, line, minimum-defense-frequency, call, fold, bet, pot, equity, regret, unverified-claim, dead-money, combos -->

## 本节目标 / Objectives

- 能用一条可算的界线描述一条行动线走到哪个节点之后"之后再弃牌"这个计划已经不自洽，并说出这条界线由哪个式子算出。
- 能分别算出两种承诺的价格：只走一级（跟完这一条街）需要多少胜率，走完剩下所有街（套池）需要多少胜率，并解释为什么前者随尺度上升、后者随节点下降。
- 能说出"对手有多常在转牌开第二枪""对手有多常在转牌过牌"这两个数在本仓库**不存在**，指出把它们变成 `derived` 的确切路径，并且不编造任何频率。

## 前置知识 / Prerequisites

- `03-07` SPR 与全下门槛：本节把同一个式子沿一条街一条街地推进，观察它在每个节点上怎么变。

## 核心原理 / The principle

在任意节点，令 `P` 为底池（含死钱）、`S` 为身后筹码。两种承诺有两个门槛：

```
只走一级：  e_call = B / (P + 2B)                 ← 跟完这一条街
套池：      e_commit = S / (P + 2S) = SPR/(1+2·SPR) ← 剩下的钱全部打完
```

若手上的胜率 `e ≥ e_commit`，那么"这一条街先跟、下一条街再决定"就是一个空洞的说法：**你已经没有可以弃牌的未来了**，因为未来每一次全下都在数学上被允许。这就是套池（pot commitment）；它不是沉没成本的说法，而是"继续投入的期望合理性"。

`e_call ≤ e < e_commit` 这一带才是试探性跟注（float）存在的空间：跟得起，但计划要靠未来某条街上对手的行为才能兑现。**而"对手的行为频率"不是本仓库能算的量**——它是本节唯一需要标记 `reference` + UNVERIFIED 的地方。

## 推导 / Derivation

**不变式。** 只看"跟注"这一条路径：跟掉 `B` 之后，底池变成 `P + 2B`，身后变成 `S − B`。把它们代进套池门槛的分母：

```
(P + 2B) + 2(S − B) = P + 2S
```

`B` 消掉了。**沿纯跟注路径，`P + 2S` 是常数——它就是这手牌全下后的最终底池。**于是第 k 个节点的套池门槛只是

```
e_commit(k) = (S − 已跟注总额) / (P0 + 2·S0)          ← 分母永远不变，分子每次少一个 B
```

严格递减。这就是"套池"的算术本体：**每跟一次注，你都把自己的全下门槛往下拽一格。**

再看单街门槛。用尺度比例 `f = B/P` 写：`e_call = f/(1+2f)`，它对 `f` 严格**递增**。两条曲线方向相反，所以必然相交——交点是本节最有用的一个式子：

```
(S − fP)/(P + 2S) = f/(1+2f)      →      2f² + 2f − SPR = 0      →      f* = (√(1 + 2·SPR) − 1) / 2
```

（把 `S = SPR·P` 代入并整理；`f*` 要求 `1 + 2·SPR > 0`，恒成立，所以平方根那一步不会失败。）`f*` 的含义：**当尺度超过 `f*`，"跟一级"的门槛已经比"套池"的门槛更高**——能跟的牌一定能全下，float 这个第三种动作在算术上不存在。三个深度用 `python -c` 算（`pokergto.spr.spr`、`all_in_equity_needed_from_spr` 与 `pokergto.odds.equity_needed_to_call`）：

- 40bb 3-bet 池（`P = 16.5, S = 32.5`，SPR `1.9697`）：`f* = 0.611237` 倍池底，两个门槛在 `27.5026%` 相交。
- 100bb 3-bet 池（SPR `5.6061`）：`f* = 1.247292` 倍池底，相交于 `35.6921%`。
- 100bb 单加注池（`P = 5.5, S = 97.5`，SPR `17.7273`）：`f* = 2.518880` 倍池底，相交于 `41.7188%`。

第三条数是"float 是深筹码概念"这句话的证明：标准尺度阶梯（`pokergto.odds.STANDARD_SIZES`）最高只到 2 倍池底，而 `2.5189 > 2`，所以在这个深度上**阶梯里每一个尺度都满足 `e_call < e_commit`**，跟注与套池仍是两个不同的动作；到 40bb 那种深度，一个 2/3 池下注（`0.6667 > 0.61124`）就已经跨过去了。

**反过来的问题**——"我这手胜率只够部分投入"——由 `pokergto.spr.max_profitable_commit_fraction` 回答。解 `S'/(P + 2S') = e` 得 `S' = eP/(1 − 2e)`，除以 `S = SPR·P`：

```
可投入比例 = e / ((1 − 2e)·SPR)         上限 1
```

这里唯一会失败的是 `1 − 2e`：`e → 1/2` 时它除向零，与 `03-07` 的反函数发散是同一件事。所以"胜率 50% 以上可以投入全部"在这里再次成立，而低于 50% 的每一手牌都有一个属于自己的、小于 1 的比例。

## 直觉 / Intuition

把一条街想成两次除法在互相靠近：

- **跟一级**的门槛只看这一手要加多少钱，尺度越大越贵；
- **套池**的门槛看你还能丢多少钱，跟得越多越便宜。

两者之间的缝隙就是"我可以继续，但我并没有承诺"的宽度。深筹码时缝隙宽（100bb 单加注池：20.00% 与 48.6284% 之间），短筹码时缝隙窄甚至反号（40bb 3-bet 池的 2/3 池下注：28.57% 与 26.38%）。

**"套池"这个词不该让你想到已经死掉的钱，它说的是剩下的钱。**本节所有式子里，`P0` 与 `S0` 已经投入的部分从不单独出现，出现的一直是"剩下多少 / 最终底池多大"。

## 算例 / Worked examples

**例 1 — 40bb 的 3-bet 池：三次除法的下坡。** CO 开池 2.5，BTN 3-bet 到 7.5，CO 跟；底池 `16.5`（含 1.5 死钱），双方身后 `32.5`。

- 翻牌开始：`P = 16.5, S = 32.5` → SPR `1.9697`，套池门槛 **39.8773%**，已投入占总筹码 18.75%。
- 跟掉 1/3 池 `5.5`：`P = 27.5, S = 27.0` → SPR `0.9818`，套池门槛 **33.1288%**；这一级只需要 **20.00%**；累计投入 32.50%。
- 跟掉转牌半池 `13.75`：`P = 55.0, S = 13.25` → SPR `0.2409`，套池门槛 **16.2577%**；这一级需要 **25.00%**；累计投入 **66.875%**。

每个数都由 `python -c` 调用 `pokergto.spr.spr / all_in_equity_needed_from_spr` 与 `pokergto.odds.equity_needed_to_call` 得到。检查不变式：分母始终是 `16.5 + 2·32.5 = 81.5`，而分子 `32.5 → 27.0 → 13.25` 正是两次跟注扣掉的 `5.5 + 13.75`。到第三个节点，"全下"只需要 16.2577%——比第一条街的跟注门槛还低 3.74 个百分点。

**例 2 — 100bb 的大盲防守：几乎没动。** BTN 开池 2.5，BB 跟（SB 的 0.5 是死钱）：`P = 5.5, S = 97.5` → SPR `17.7273`，套池需要 **48.6284%**。BB 跟掉翻牌 1/3 池 `1.8333` → `P = 9.1667, S = 95.6667` → SPR `10.4364`，门槛 **47.7140%**，而这一级只需要 **20.00%**。跟掉转牌底池下注 `9.1667` → `P = 27.5, S = 86.5` → SPR `3.1455`，门槛 **43.1421%**，累计只投入了总筹码的 **13.5%**。**同样的两次跟注，40bb 线里把门槛砍掉 23.62 个百分点，100bb 线里只砍掉 5.49 个百分点**（39.8773−16.2577 与 48.6284−43.1421）。

**例 3 — 一手牌落在缝隙里。** `python -m pokergto equity "T9o" "AKo,AQo,AJs,ATs,KTs,QQ,JJ,TT" --board "As9s5d" --json` 给出 **0.221839**。

- 就在 BTN 下完 1/3 池、BB 还没跟的那个节点：一级门槛 **20.00%**（多出 2.1839 个百分点，`ev_call(5.5, 5.5/3, 0.221839) = +0.200191` 筹码），套池门槛 **48.6284%**（`SPR = 17.7273`），`max_profitable_commit_fraction(17.7273, 0.221839) = 0.022494` → 这手牌只买得起身后筹码 **2.25%**。
- 跟完之后（`SPR = 10.4364`）门槛降到 **47.7140%**、可投入比例升到 `0.038209`（**3.82%**）；再跟一次转牌底池下注之后（`SPR = 3.1455`）门槛 **43.1421%**、比例 `0.126772`（**12.68%**）。

**每跟一次，门槛往下走、可投入比例往上走**，但两个数之间的缺口在整条线上都还有 20 个百分点以上（48.6284 / 47.7140 / 43.1421 对比手里的 22.1839）。

**例 4 — 尺度怎么把缝隙关掉（同一节点，四种翻牌下注）。** 40bb 3-bet 池，`P = 16.5, S = 32.5`：

- 1/3 池 `5.5`：一级 20.00%、跟完后套池 33.1288%；
- 1/2 池 `8.25`：一级 25.00%、套池 29.7546%；
- 2/3 池 `11.0`：一级 **28.5714%**、套池 **26.3804%** ← 缝隙已经反号；
- 底池 `16.5`：一级 33.3333%、套池 19.6319%。

结论是可算的，不是口味的：**在这个深度上，2/3 池及以上的下注取消了"跟了再说"这个选项**（能跟的门槛比能套的门槛高），交点就是上面推出来的 `f* = 0.611237`。

**例 5 — 反打需要多少弃牌率（这是尺度自身的性质，与底池大小无关）。** `python -m pokergto odds --pot 1` 打印的 MDF 列取补即得：1/3 池要 25% 弃牌率（MDF 75%）、1/2 池 33.33%（MDF 66.67%）、2/3 池 40%（MDF 60%）、底池 50%（MDF 50%）。所以在例 2 的转牌节点用半池反打，需要对手在三分之一的情况下放弃——**这个"三分之一"是从尺度推出来的，不是从对手身上量出来的。**

**例 6 — 隐含赔率是 float 的账本，而账本上有未填的空。** 同一个转牌节点（`P = 9.1667, B = 9.1667`）：`pokergto.spr.implied_odds_break_even_equity` 给出，若预期未来还能赢进 20，门槛从 **33.3333%** 降到 **19.2982%**——`T9o` 的 22.1839% 因此越过；反之若预期未来要付出 15，`reverse_implied_odds_penalty` 给出 **87.8788%**。同一条式子，两种命运，而唯一的区别是那个未来金额——它属于下一节要标 UNVERIFIED 的东西。

## 实战牌局 / Live hands

**牌局 1（`hand.03-08-adkc-40bb-commit`）— 三个节点全部越线，所以这条线里没有"再说"。**

座位与钱：6 人局，所有人 40bb。CO 拿 `AdKc` 开池 2.5，BTN 3-bet 到 7.5，CO 跟。翻牌 `Kh7s3d`，底池 `16.5`，CO 身后 `32.5`（SPR `1.9697`，套池门槛 **39.8773%**）。

- `AdKc` 对 BTN 声明的 3-bet 范围 `"AA,KK,QQ,JJ,TT,98s,AKs,AQs,AKo,AQo"` 的胜率是 **79.4731%**（`python -m pokergto equity "AdKc" "AA,KK,QQ,JJ,TT,98s,AKs,AQs,AKo,AQo" --board "Kh7s3d" --json`）。79.47% 在翻牌就是套池门槛的两倍，因此决策不是"要不要跟"，而是"用哪个尺度把剩下的钱推进去"。
- BTN 下 5.5（1/3 池）：`ev_call(16.5, 5.5, 0.794731) = +16.3551` 筹码；BTN 若改下 11.0（2/3 池），跟完之后套池门槛降到 26.3804%，而 `ev_call(16.5, 11.0, 0.794731) = +19.5971` 更高。这不是"对手越大越欢迎"，是一条代数：`ev_call = e·P + B·(2e − 1)`，当 `e > 1/2` 时它随 `B` 递增——`03-07` 的那个 50% 上限在这里第二次出现。
- 转牌 `2c`，BTN 半池 13.75 进 27.5：一级门槛 25.00%，套池门槛 16.2577%。79.47% 两者都远远盖过，`ev_call(27.5, 13.75, 0.794731) = +29.9602`。此时"底池控制"式过牌的代价就是这 29.96 个筹码——约等于半个底池白送给对手一个不该存在的决定。
- 河牌只剩 13.25，底池 55：**这条线在翻牌就没有"收着打"这个分支了**，因为套池门槛（39.88%）已经低于手里的胜率（79.47%）将近 40 个百分点。

**牌局 2（`hand.03-08-t9o-float-unpriced`）— 跟得起，计划算不出来。**

座位与钱：100bb，BTN 开池 2.5，BB 用 `T9o` 跟注（SB 弃，0.5 记为死钱）。底池 `5.5`，BB 身后 `97.5`，SPR `17.7273`，套池需要 48.6284%。翻牌 `As9s5d`，BTN 下 1/3 池 `1.8333`。

- 单街：跟注门槛 **20.00%**，`T9o` 对 BTN 声明的下注范围 `"AKo,AQo,AJs,ATs,KTs,QQ,JJ,TT"` 的胜率是 **22.1839%**（`python -m pokergto equity "T9o" "AKo,AQo,AJs,ATs,KTs,QQ,JJ,TT" --board "As9s5d" --json`），`ev_call = +0.200191`。**跟注这一半是可算的，而且是正的。**
- 套池：在同一个（尚未跟注的）节点上门槛是 **48.6284%**，比手里的 22.1839% 高出 26.4445 个百分点，`max_profitable_commit_fraction(17.7273, 0.221839) = 0.022494` 说得更直白：只买得起 2.25%。所以"跟完之后如果他又开一枪怎么办"必须提前有答案。
- 转牌 `2c`，BTN 底池下注 `9.1667`：门槛跳到 **33.3333%**，`ev_call(9.1667, 9.1667, 0.221839) = −3.066094`。**除非未来有钱可赢**：只要"未来还能赢进 20"成立，门槛就是 19.2982%（例 6）。而"他有多常在转牌开第二枪""他过牌之后我反打能不能拿下"这两个频率，本仓库没有任何产物、任何命令能给出——**这就是 float 的定义性缺口**，不是本节没写完的部分。
- 可算的那一半继续算给你：BB 在转牌用半池反打需要对手 **33.33%** 的弃牌率（例 5）。所以正确的说法是："如果 BTN 在这条线上有至少三分之一的频率不继续，那么反打有价格"——**条件是未核验的，价格是推导的。**

## 为何成立、何时失效 / Why it works, when it breaks

**成立的前提**：筹码线性；跟注之后唯一可能的未来动作是"再跟/全下/弃牌"；`S > 0`（一旦 `S ≤ B`，"跟了再看"这句话自己失效，剩下的只有弃或推——这正是套池的操作定义）。

**需要改写的地方**：

1. **你的全下可能被弃牌。** 那时 `e_commit` 是下界的下界，正确工具是 `break_even_equity_to_bet(pot, bet, f)`：`f` 非零时门槛会低于纯摊牌值。例：`break_even_equity_to_bet(27.5, 27.0, 0.35)` 给出 regime `above`、门槛 **31.1089%**，而同一节点的摊牌式套池门槛是 33.1288%。
2. **胜率不是常数。** 例 1 与例 2 的门槛都是"这手牌的平均胜率"，而真实胜率随转牌与河牌变化；把"翻牌套池"读成"任何两张之后都套池"是错的。牌面发展与坚果容量的关系在 `03-03` 与本卷 `03-09`。
3. **多人底池。** "全下"要一次赢两家，门槛的含义改变（见 `03-09` 与 `07-01`）。
4. **ICM。** 淘汰风险使"剩下的钱"不再是线性的，本节的下坡曲线全部失效（第 12 章）。
5. **未核验的那一格：未来频率。** float 的全部 EV 来自"未来某条街上对手的行为"。本仓库现有求解器只有单街游戏（`src/pokergto/solver/games.py` 的 `kuhn` 与 `one_street_bluff_catcher`，注册在 `pokergto.solver.proofs.PUBLISHED_PROOFS`），所以没有第二枪频率可算。**把它变成 `derived` 的确切路径**：在 `games.py` 里加一棵两街游戏树（翻牌下注/跟注 → 转牌第二次下注），在 `PUBLISHED_PROOFS` 里给它一条锚点（`tools/run_solver.py` 的规则是"没有锚点就没有产物"），跑出 `data/gen/solver/solver.<game>.json`，再由 `tools/gen_tables.py` 出成 `table.*` 产物——之后本节才允许写一个频率。

## 陷阱 / Common mistakes

1. **用沉没成本解释套池。** 正确式子里没有"已经投入"这一项：例 1 第三个节点的门槛是 `13.25/81.5 = 16.2577%`，全部信息是"剩下的钱 / 最终底池"。*代价*：沉没成本论证会让你在例 2 的转牌节点跟 `T9o`，`ev_call(9.1667, 9.1667, 0.221839) = −3.066094` 每手——而"我已经跟过一次了"在这个数字里出现零次。
2. **把"跟一级"的门槛当成整条线的门票。** 在 BTN 下完 1/3 池的那个节点上，20.00% 与 48.6284% 相距 **28.6284 个百分点**（例 3）。*代价*可以精确到比例：`max_profitable_commit_fraction(17.7273, 0.221839) = 0.022494`——多投的每一分都在买这手牌并不持有的胜率；反过来说，把只够 2.25% 投入的牌打成套池，等于在 SPR `17.7273` 上支付 48.6284% 的价钱。
3. **为 float 编一个对手频率。** 常见的说法是"他翻牌持续下注之后有 60% 会在转牌放弃，所以 float 有利"。本仓库没有任何命令能给出那个 60%，所以那句话不是策略结论而是虚构。*代价*是可算出的敏感度而非固定数：在半池反打需要 33.33% 弃牌率（例 5），若真实频率只有 25%，同一动作的价格就变成 `ev_pure_bluff(9.1667, 4.5833, 0.25) = −1.1458` 每手；频率正好是推导出的临界值 1/3 时 `ev_pure_bluff(9.1667, 4.5833, 0.333333) = +0.000029`（空气反打无差别，`02-03` 的那条等式在这里第三次出现）；频率升到 40% 才是 `+0.9167`。**结论完全悬在那个未核验的输入上，而算术本身一直是清的。**

## 练习 / Drills

- 例 1 的线里把翻牌下注换成 1/2 池：跟完之后 SPR 与套池门槛各是多少？（`24.25/33.0` → SPR `0.7348`，门槛 **29.7546%**，一级门槛 25.00%）
- 用 `python -c` 检查不变式：在 40bb 线上算 `P + 2S`，跟一次 5.5 之后再算一次。（两次都是 `81.5`）
- 40bb 线的第三个节点，套池门槛掉到多少？它比第一条街的跟注门槛高还是低？（**16.2577%** vs 20.00%——门槛已经更低，所以"先跟后弃"在这条线上不自洽）
- 交点：SPR `1.9697` 时 `f* = ?`（`(√(1+2·1.9697) − 1)/2 = 0.611237` 倍池底，此时两个门槛都是 `27.5026%`）。SPR `17.7273` 时呢？（`2.518880` 倍池底，超出标准阶梯）
- 用 `max_profitable_commit_fraction` 排一张表：`SPR ∈ {1, 2, 4}` × `e ∈ {0.30, 0.35, 0.40}`，找出所有等于 1 的格子，并解释它们与 50% 上限的关系。（`SPR 1, e 0.35 → 1.0`；`SPR 2, e 0.35 → 0.5833`；`SPR 4, e 0.35 → 0.2917`；`SPR 1, e 0.30 → 0.75`）
