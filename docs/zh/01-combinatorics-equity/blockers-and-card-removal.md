# 阻断牌与移除效应：一张牌如何改掉对手的组合计数

<!-- hands: 2 -->
<!-- terms: blocker, removal-effect, combos, hand-class, range, flush, straight, board, equity, pocket-pair, suited, offsuit -->

## 本节目标 / Objectives

- 能给任意一个手牌类别算出"移除一张指定牌之后还剩几个组合"，并解释为什么移除两张牌的结果取决于这两张牌是否同花。
- 能量化一张牌对同花、顺子、对子三类牌型供给的冲击，并说清哪个类的**百分比**损失最大。
- 能说清"你拿着这张牌"如何改变**对手**的分布，而不只是改变你自己的牌力。
- 知道本引擎的移除效应建模到哪一层，超出这一层的说法要标成未核验。

## 前置知识 / Prerequisites

- `01-01` 组合数：`6 / 4 / 12` 与 `1326`。本节的每一次减法都发生在这张底座上。
- `00-01` 牌面与街道：知道哪些牌是"可见的"。
- 容斥原理：`|A ∪ B| = |A| + |B| − |A ∩ B|`。

## 核心原理 / The principle

**移除效应是一句减法**：某张牌一旦可见（你自己的底牌、公共牌面、摊牌时对手亮出的牌），所有包含这张牌的组合同时消失。

对同一个类，删掉的绝对数量只和这张牌在该类里参与了几个组合有关：

| 类（可见牌） | 总组合 | 含这张牌的组合 | 剩余 |
|---|---|---|---|
| `AA`（`As`） | 6 | 3 | 3 |
| `AKs`（`As`） | 4 | 1 | 3 |
| `AKo`（`As`） | 12 | 3 | 9 |
| `KK`（`As`） | 6 | 0 | 6 |

最后一行比前三行更重要：**同一张 `As` 让 `AA` 少一半、让 `AKo` 少四分之一、让 `KK` 一点不少。** 这些数字不是记住的，是 `Range.with_removed()` 现算的。

**同一张牌在不同范围里的价值可以相差到 0。** 一张不在对手范围里的牌，删除的组合数是 0，它对这手牌的信息量为 0。

## 推导 / Derivation

**一张牌。** 设类别为 `RX`（`R ≠ X`），可见牌是 `Rs`（点数 R、花色 s）。

- 对子 `RR`：`C(4,2) = 6` 个组合里含 `Rs` 的有 `C(3,1) = 3` 个（`Rs` 配其余三张 R），剩 `6 − 3 = 3`。
- 同花 `RXs` 类：同花组合必须是同一花色的两张牌，`Rs` 只能配 `Xs`，所以恰好 1 个，剩 `4 − 1 = 3`。
- 不同花 `RXo` 类：`Rs` 可以配 `X` 的其余三种花色，共 3 个，剩 `12 − 3 = 9`。
- 若可见牌的点数不在这个类里：减 0。

**两张牌。** 用容斥。以 `AKo` 为例，可见 `As` 与 `Kh`：

```
含 As 的组合 = 3，含 Kh 的组合 = 3，
而 AsKh 本身就是 AKo 的一个组合 → 交集 = 1
12 − 3 − 3 + 1 = 7                                    （引擎给出 7）
```

如果可见的是 `As` 与 `Ks`：`AsKs` 属于 `AKs` 而不是 `AKo`，交集为 0：

```
12 − 3 − 3 = 6                                        （引擎给出 6）
```

**同花组合数。** 牌面已经有两张红心（`Kh 7h 2d`），红心剩 `13 − 2 = 11` 张，两手都红心的组合是 `C(11,2) = 55`。再移除一张红心（例如你拿着 `Ah`），变成 `C(10,2) = 45`：**少 10 个，占原来的 18.18%**。你手里如果两张都是红心，剩 `C(9,2) = 36`。

**顺子组合数。** 牌面 `9h 8h 2s`，`JT`（两头顺的底子）共有 `JTs 4 + JTo 12 = 16` 个组合；`Th` 一死就只剩 12（`JTs 3 + JTo 9`），因为 `Th` 参与了 1 个同花组合和 3 个不同花组合。

## 直觉 / Intuition

阻断牌不是"我有它他就少"的模糊话，而是**一次具体的减法**。三句话就能把直觉装进口袋：

- **薄的类最怕被删。** `AKs` 只有 4 个组合，一张牌就能拿掉四分之一；`AKo` 有 12 个，同样一张牌只拿掉四分之一（比例巧合地相同），但对子 `AA` 一张牌就少一半。**同一张 `As` 让 `AA` 损失 50%，让 `KK` 损失 0%。**
- **删价值比删诈唬好，删诈唬比不删好。** 你要做诈唬时，希望对手"能跟注的组合"少、"会弃牌的组合"也多——两个方向相减才是净效果。`01-01` 牌局 1 里 `Qc Jc` 比 `Kc Jc` 每手差 2.4 个筹码，就是这么来的。
- **对方的范围里没有的牌，阻断价值为零。** 这是本节最容易忘、也最贵的一条。

心智模型：把对手的范围想成一堆**库存盒子**（每格 4/6/12 件）。你亮出一张牌，就是从所有含这张牌的盒子里各拿走一件。盒子越薄，被拿走的百分比越大；空盒子什么都不会发生。

## 算例 / Worked examples

**例 1 — `AKo` 的三档。** 起点 12。可见 `As` → **9**。可见 `As, Kh` → **7**。可见 `As, Ks` → **6**。三个数字都来自 `parse("AKo").with_removed(...)`。差别的来源就是那个交集：`AsKh` 是一个 `AKo` 组合，`AsKs` 不是。

**例 2 — 整条 `AK`（同花加不同花，16 个组合）。** 可见 `As` → 12（`AKs` 3 + `AKo` 9）。再可见 `Kh` → 9（`AKs` 2 + `AKo` 7）。**"AK 一共有 16 个组合"这句话只要你手里有一张 A，就已经不成立了。**

**例 3 — 红心供给。** 牌面 `Th 9h 5d 3c 2s`：红心剩 11 张，`C(11,2) = 55` 个同花组合。
- 你拿着 `Ah`：对手还剩 **45** 个同花组合，而且那 10 个"包含 `Ah`"的组合（`Ah` 配其余 10 张红心）**全部消失**——也就是说，对手所有可能的同花里，坚果同花一个都不剩。
- 你拿着 `Ad Td`（不含红心）：对手的 55 个一个不少。
**同一张牌，删掉的组合数完全取决于对手范围里有没有它。**

**例 4 — 一个 4-bet 价值范围。** 对手全下范围 `QQ+,AKs` = 22 个组合（对子 18 + `AKs` 4）。
- 你拿着 `As`：`AA` 6→3，`AKs` 4→3，合计 **18**。**你一个人删掉了对手价值范围的 18.2%。**
- 你拿着 `As Kc`：`AA` 3、`KK` 3、`QQ` 6、`AKs` 2 = **14**。结构也变了：`对子:AKs` 从 `18:4 = 4.5:1` 变成 `12:2 = 6:1`。
- 比例的变化比总数更重要：剩下来的组合里"翻你前面的对子"占了绝大多数。这就是拿着 `AKo` 时对全下范围里含 A 含 K 的牌要格外小心的算术理由（`AKo` 对 `QQ+,AKs` 的胜率是 33.03% ±0.66pp，`n = 20000`、`seed = 6`，其中 13.7% 是平分——`AKo` 撞上 `AKs` 的那部分）。

**例 5 — 一张 committed 的图。** 本仓库的半池 MDF 底线图（`02-03`，`data/gen/ranges/range.02-03.mdf-floor-vs-half-pot.json`）覆盖 884 个组合。对它的 `weights` 逐组合枚举，做移除：

| 可见牌 | 图上损失的组合数 | 剩余 | 占 1326 |
|---|---|---|---|
| `Ah` | 43 | 841 | 63.42% |
| `As` | 43 | 841 | 63.42% |
| `Kh` | 43 | 841 | 63.42% |
| `Th` | 43 | 841 | 63.42% |
| `2h` | **0** | 884 | 66.67% |

`2h` 那一行是本节的全部内容：**这张牌在那个防守范围里根本不存在**（图上的 114 个非空格子里不含 `2h` 参与的组合），所以它作为阻断牌一文不值。四行 43 与一行 0 之间的差别，比任何"我有阻断牌"的口号都更有用。

## 实战牌局 / Live hands

**牌局 1（`hand.01-02-river-flush-blocker`）— 单挑，河牌 `Th 9h 5d 3c 2s`，底池 100。BTN 面对 BB 的跟注全下。**

Hero（BTN）拿着 `Ah 6d`：翻牌圈的两对没有、同花没有（只有一张红心），只能打赢空气。BB 全下 100（底池尺度），Hero 跟 100 进 300，需要 `100/(100+200) = 33.33%` 胜率。抓诈唬牌只能赢空气，所以条件就是"空气在他全下范围里的占比 ≥ 33.33%"。

按示例范围逐项数组合（牌面已经移除）：

- 价值 = 同花 `C(11,2) = 55` + Set `55,33,22` 各 3 = 9 → **64**。
- 诈唬（没中的顺子听牌一类）= `KQo, KJo, QJo` = 12+12+12 = **36**。
- 空气占比 `36/(64+36) = 36.0%` > 33.33% → **跟注**。

Hero 的 `Ah` 在这里的作用不是牌力，而是**它从对手的价值侧删掉了 10 个组合**：`64` 变成 `54`，于是空气占比变成 `36/(54+36) = 40.0%`。**同样的牌面、同样的范围写法，胜率余量从 +2.7 个百分点涨到 +6.7 个百分点。**
反过来看灵敏度：如果对手的诈唬侧只有 30 个组合，没有阻断牌时 `30/94 = 31.91%` 是**弃牌**，拿着 `Ah` 时 `30/84 = 35.71%` 就成了**跟注**——阻断牌在这里直接翻转了决策。

**牌局 2（`hand.01-02-four-bet-shape`）— 翻前。Hero（BTN）拿着 `As Kc`，BB 面对开池全下，范围写作 `QQ+,AKs`。**

- 起点：`QQ+,AKs` = 22 个组合，`AKo` 这一类对它 33.03% ±0.66pp（`n = 20000`, `seed = 6`）。
- 你的手牌把对手的范围删成 `AA 3 + KK 3 + QQ 6 + AKs 2 = 14` 个组合：**少了 36%**。
- 重要的是**形状**：剩下的 14 个里，12 个是"对子翻你在前面"，2 个是 `AKs`（跟你平分或靠同花取胜）。`对子:AKs` 从 `4.5:1` 变成 `6:1`。
- 决策语言：如果你要评估跟全下，先问"他这个范围里我还剩什么可打"，把 14 个组合按类别摊在桌上——`As Kc` 让 `AA` 少一半、`KK` 少一半、`AKs` 少一半，这三笔减法同时发生，正是你手上这两张牌的作用。**牌力没变，对手的库存变了。**

```python
from pokergto.notation import parse
from pokergto.cards import Card
parse("QQ+,AKs").with_removed(Card.parse("As"), Card.parse("Kc")).classes()
# {'AA': 3.0, 'KK': 3.0, 'QQ': 6.0, 'AKs': 2.0}
```

## 为何成立、何时失效 / Why it works, when it breaks

**成立的前提**：你数的是**物理组合**的供给，而且那个范围确实包含这些组合。前者是发牌机的事实，后者是对手策略的事实。

失效或需要谨慎的地方：

1. **引擎的移除效应只做在两处。** 一是 `Range.with_removed()`：在 1326 个底牌组合里把含指定牌的组合置零，本节的减法全部来自这里；二是 `pokergto.equity.runout_boards(board, known_hands=...)`：发牌空间会因为已知的牌而缩小（`01-03` 里 `1176 / 1081 / 990` 三档就是它）。**引擎不会自动把一个范围在多条街上的移除效应连起来算**，涉及"他翻牌的概率也变了"这类二级效应，本节不给数字。
2. **供给不等于频率。** `AKs` 只剩 3 个组合，不代表对手用这 3 个组合的频率是 100%。移除效应回答"有多少"，不回答"打不打"。
3. **多人底池里，移除效应叠加。** 三个人各自拿着牌，同一张牌被删四次。`02-03` 的多人 MDF 公式假设防守者**独立**，牌力移除正是打破这个假设的机制之一，所以那条公式在多人底池里是近似——本仓库把它记在 artifact 的 `provenance.assumptions` 里，`07-01` 处理它。
4. **记法层面的损失。** `pokergto.notation` 表达不了"只要 `AsKs` 这一张"，所以按类做的减法在物理子集层面可能不精确（`to_spec()` 会标 `lossy`）。本节所有例子都在类这一层，可以精确；一旦你要说"他只有红心那一手才跟注"，就不是记法能算的东西了。

## 陷阱 / Common mistakes

1. **阻断一张不在对手范围里的牌。** 例 5 的 `2h`：删除 0 个组合。
   *代价*：这是"用阻断牌为不成立的诈唬辩护"的源头。先问"他的范围里有这张牌吗"，再问"有几个组合"。
2. **忘记容斥。** 认为两张可见牌一定删 6 个 `AKo` 组合。实际 `As+Kh` 删 5（交集 1），`As+Ks` 删 6。
   *代价*：`7` 与 `6` 看着差别小，但在"诈唬需要几个组合"的比例上，一次除法就把它放大成弃牌率的分差。用 `with_removed(*cards)` 一次算完，不要手加。
3. **把移除当成牌力。** `As Kc` 对 `QQ+,AKs` 的胜率仍然是 33.03%（`n = 20000`，误差 ±0.66pp）：范围被删小，不等于你从落后变成领先。
   *代价*：在"我删了他的牌，所以我领先"的直觉下跟了全下。移除效应改变的是**分布的形状**，胜负要看胜率本身。
4. **只报绝对数、不报百分比。** `AKs` 少 1 个（−25%）和 `AKo` 少 1 个（−8.3%）不是同一件事；`AA` 少 3 个（−50%）才是最剧烈的一档。
   *代价*：把阻断牌的强度排错序，于是选错了诈唬候选牌。

## 练习 / Drills

- 手算后用 `with_removed` 复核：牌面 `Kd 8c 3h`，对手范围 `KK,AKs,AKo,KQo,QQ,JTs`。每个类各剩几个组合？合计多少？
- 容斥练习：`QJo` 在可见 `Qs, Jh` 之后剩几个？`Qs, Js` 之后呢？先猜交集，再算。
- 把例 3 换成黑桃：牌面 `Ts 8s 4c`，同花组合起点是多少？移除 `As` 之后是多少？百分比损失是多少？
