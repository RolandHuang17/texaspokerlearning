# Support

## This project is free and open. That is the point.

Commercial GTO tools are excellent and expensive, and the barrier they create is exactly the
one this repository exists to remove: the *reasoning* behind optimal play is public mathematics,
and it can be derived and verified with a laptop.

## If you want to help

Priority order, cheapest and most useful first:

1. **Use it and report what confuses you.** Open a "Derivation request" issue with the lesson id
   and the sentence where you got lost. "I could not follow why MDF is `pot/(pot+bet)`" is the
   single highest-value issue type in this repository.
2. **Fix a factual or arithmetic error.** Tests that fail on your fix are ideal. The engine is
   the authority, so a claim can be wrong only if the code that generates it is.
3. **Author a lesson**, bilingual, following `docs/_template/lesson.md.tmpl` and
   `CONTRIBUTING.md`. Both languages in one pull request.
4. **Add a verified live hand example** to `data/src/hands/` with its provenance block.
5. Star it, cite it, or send it to someone who is stuck playing by feel.

## What this project will not accept

- Range charts or strategy data copied from commercial solvers or paid courses (see `NOTICE`).
- Features that turn it into a real-time assistance tool against other players.
- Content that presents unverified folk wisdom as fact; the `UNVERIFIED` badge exists so that
  honesty is visible rather than implied.
